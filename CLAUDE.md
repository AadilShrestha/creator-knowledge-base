# Creator knowledge-base workspace

@AGENTS.md

Claude Code: the imported `AGENTS.md` is the operating manual. This repository stores a persistent Markdown wiki for e-commerce marketing, copywriting, and ad creation, with creator attribution and source citations.

Start from the repository root. Existing knowledge is in `knowledge-base/wiki/`; original downloads live locally in `knowledge-base/raw/`; derived text evidence in raw `_transcripts/` and `_extracted/` is tracked by Git. New creator knowledge goes in `knowledge-base/wiki/courses/<creator>/<course>/`, with selected images in `knowledge-base/wiki/assets/<creator>/<course>/`.

For course ingestion, read the course's `PROGRESS.md`, `manifest.json`, and `index.md`, creating them if needed. Set up the local tools, process sources, and save work after each batch. Finish only with source coverage and validation evidence. This workflow runs directly in a local folder; Git operations are optional and require an explicit request.
