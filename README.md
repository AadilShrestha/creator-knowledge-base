# Creator knowledge base

A growing Markdown reference for e-commerce marketing, copywriting, customer research, and ad creative. Based on [Karpathy's LLM Wiki pattern](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f): preserve sources, compile linked knowledge, record changes.

- Read existing knowledge: [wiki index](knowledge-base/wiki/index.md) and [overview](knowledge-base/wiki/overview.md).
- Agent instructions: [AGENTS.md](AGENTS.md); Claude Code loads [CLAUDE.md](CLAUDE.md).
- Friend on a Mac: [setup guide](handoff/MAC-SETUP.md), then [copy-paste prompt](handoff/FRIEND-PROMPT.md).
- Share through Discord: [ready message](handoff/DISCORD-MESSAGE.md).
- Repository owner: [GitHub setup and merge guide](handoff/OWNER-GITHUB.md).

## Current state

The initial Tether Lab wiki contains 251 Markdown pages, 36 transcript text files, and 201 wiki images at the handoff baseline. Its libraries, playbooks, rubrics, and some navigation links remain unfinished. Existing pages are useful reference, not proof of exhaustive source coverage.

Evolve Copywriting and Evolve Start Here are assigned to the friend on `contrib/friend-creators`. Their manifests inventory the remote files; the course content is **not ingested yet**. New creators get separate folders, and shared synthesis follows review.

## What Git shares

Git tracks Markdown, source inventories, progress, derived transcripts/extracted text, small useful screenshots, and portable helpers. Original videos, audio, documents, model downloads, credentials, and temporary files stay on each contributor's computer. Local raw sources must be downloaded again on a second computer; tracked text evidence remains available for review.

Open `knowledge-base/` as an Obsidian vault if you want a visual browser. No database or hosted app is required.
