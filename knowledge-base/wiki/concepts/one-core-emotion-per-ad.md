# One Core Emotion per Ad (Supporting Characters Only Support)

> **"Communicating one core emotion at a time and supporting that core emotion with other things that are going to back it up… all we're trying to do is raise dopamine one time."** One headline, one CTA; stars, badges and call-outs are supporting characters ([Roast My Ads #1](../courses/tether-lab/05-live-recordings/2025-05-28-roast-my-ads-1.md) [0:41:46–0:42:48]).

## 🤖 Agent use
- **Use when:** QA-ing any static or UGC script before production; tearing down a competitor ad that feels busy; deciding what to cut.
- **Inputs → outputs:** a draft ad → the one core emotion it sells, a list of elements that support it, a list of elements that compete with it (cut or demote), and a pass/fail.
- **Rules:**
  - DO give each ad **one headline, one CTA, one emotion** ([Roast My Ads #1](../courses/tether-lab/05-live-recordings/2025-05-28-roast-my-ads-1.md) [0:41:46]).
  - DO make the headline carry the core value: "The headline is key, especially for statics… that communicates the core of the value" [0:42:48–0:43:52].
  - DO demote heuristics to support: five stars, reviews, badges, buttons, bullets, call-outs, prices are "not the core message, that's just a secondary supporting character" ([Live, June 4](../courses/tether-lab/05-live-recordings/2025-06-04-live-with-sarah.md) [0:33:26–0:34:31]; [Roast My Ads #3](../courses/tether-lab/05-live-recordings/2025-07-23-roast-my-ads-3.md) [0:17:51–0:18:56]).
  - DO lock the core message before adding heuristics: "Heuristics for me are secondary characters" ([Live, May 7](../courses/tether-lab/05-live-recordings/2025-05-07-live-with-sarah.md) [0:13:03–0:13:29]).
  - DON'T stack two emotional reasons as two headlines ("two totally different emotional reasons") ([Roast My Ads #1](../courses/tether-lab/05-live-recordings/2025-05-28-roast-my-ads-1.md) [0:41:46]).
  - DON'T "over-communicate": "Marketers love to over-communicate" [0:42:48].
  - IF two emotions have each won separately THEN a headline + subhead blend is allowed (see [blended emotions](blended-emotions.md)).
- **See also:** [Core brand emotion](core-brand-emotion.md) · [Blended emotions](blended-emotions.md) · [Processing fluency](heuristics/processing-fluency.md) · [Cognitive load](heuristics/cognitive-load.md) · [Heuristic stacking](heuristic-stacking.md) · [Emotional trigger](heuristics/emotional-trigger.md)

## Definition
Each ad should create one emotional spike. Everything else on the frame or in the script either backs up that emotion (proof, badges, product shot) or gets cut. "The brain gets a little tired when it's asked to process so much emotion" ([Roast My Ads #1](../courses/tether-lab/05-live-recordings/2025-05-28-roast-my-ads-1.md) [0:41:46–0:42:48]).

The Prompt Library says the same at the lever level: [Emotional trigger](heuristics/emotional-trigger.md) asks you to pick **one** core feeling and amplify it.

## Why it matters
- The brain decides in about **0.2 s** ([Live, May 7](../courses/tether-lab/05-live-recordings/2025-05-07-live-with-sarah.md) [0:13:29]); two emotions can't both land in that window.
- Supporting elements read as noise if they compete: busy layouts trigger [cognitive load](heuristics/cognitive-load.md).
- "Core message is everything. If you don't know what the message is, or you're a little fuzzy on it, people can feel it through the screen" ([Live, June 18](../courses/tether-lab/05-live-recordings/2025-06-18-live-with-sarah.md) [1:01:19]).
- When moving a winner to video, the core message must survive: Net Positive's video dropped "Ditch Polyester" to halfway and lost sales ([Roast My Ads #3](../courses/tether-lab/05-live-recordings/2025-07-23-roast-my-ads-3.md) [0:18:56–0:21:32]).

## How to use it
1. Write the ad's emotion in one word (specific, see [emotion specificity](emotion-specificity.md)).
2. List every element. Mark each "supports" or "competes".
3. Cut competing headlines; keep **one headline + one CTA**.
4. Make the headline the visually heaviest element; supporting elements lighter ([visual weight hierarchy](../frameworks/visual-weight-hierarchy.md); [Roast My Ads #1](../courses/tether-lab/05-live-recordings/2025-05-28-roast-my-ads-1.md) [0:19:55–0:23:01]).
5. For video: put the core message in frame 1, before the model or product ([Roast My Ads #3](../courses/tether-lab/05-live-recordings/2025-07-23-roast-my-ads-3.md) [0:20:01]).
6. Only then add 1–2 heuristic badges as supporting characters.

## Deploy in a UGC script
| Script slot | Pattern | Example line |
|---|---|---|
| Hook | The single emotion, stated or shown | "Ditch polyester." on screen before the creator appears ([Roast My Ads #3](../courses/tether-lab/05-live-recordings/2025-07-23-roast-my-ads-3.md) [0:20:01]) |
| Body | Proof that supports that emotion only | Reviews, demo, badge, all pointing at the same feeling |
| CTA | One action | "Sign up" / "Order yours now" (see [active CTA language](active-cta-language.md)) |

**Visual cues:** one focal object, one headline in white space, supporting proof small and peripheral.

## Spot it in a competitor ad
- Two or more headlines of similar weight, or a headline plus an "emotional bridge" that says something different.
- Badges, stars and bullets fighting the headline for attention.
- Tag: `concept-one-core-emotion` with `pass` / `fail-multi-emotion` / `fail-heuristic-as-message`.

## Rules of thumb
- **DO** headline first, heuristics second, format fourth ([Live, May 7](../courses/tether-lab/05-live-recordings/2025-05-07-live-with-sarah.md) [0:13:03; 0:38:29]).
- **DON'T** promote supporting elements to the main message ([Roast My Ads #1](../courses/tether-lab/05-live-recordings/2025-05-28-roast-my-ads-1.md) [0:43:41]).
- **IF** you need a second emotion **THEN** prove it separately, then blend as headline + subhead.

## Common mistakes
- Treating "DTC best practices" (stars, badges, bullets) as the message.
- Keeping a clever second line because you like it.
- Losing the core message in the static → video conversion.
