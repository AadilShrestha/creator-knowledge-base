# Tether Lab: Sarah Levinger
> A Skool community and course on **consumer psychology and behavioral science for DTC ad creative**: why people buy (the subconscious, heuristics, emotion, identity) and how to engineer ads, UGC scripts and landing pages around it. It has 7 modules: 4 core courses, 16 live recordings, a toolkit and a prompt library.

## 🤖 Agent use
- **Use when:** any task in the ad pipeline. Diagnosing why a competitor's ad works or why ours doesn't, generating angles and hooks, writing UGC scripts, briefing creators, structuring tests, auditing landing pages.
- **Inputs → outputs:** a competitor ad / our product / our draft → Tether Lab lenses (heuristics, valence × intensity zone, which self, TEEP stage) → a diagnosis, angle variants, a script, a test plan.
- **Rules:**
  - **DO** analyse every ad through the four core lenses. Each has a framework you can run:
    1. **Heuristics** used: [hub](../../concepts/heuristics.md).
    2. **Emotional zone** (valence × intensity): [diagnostic](../../frameworks/valence-intensity-diagnostic.md).
    3. **Self** targeted (actual / ideal / ought): [diagnostic](../../frameworks/three-selves-diagnostic.md).
    4. **Journey stage**: [TEEP](../../frameworks/teep-journey.md).
  - **DO** follow Sarah's priority order: **identity → emotion → behavior/tactics**. Heuristics are "secondary characters" ([May 7](05-live-recordings/2025-05-07-live-with-sarah.md)).
  - **DO** create variants by moving a winner to a *different* zone or self, not by inventing net-new concepts ([rewriting for new selves](../../frameworks/rewriting-ads-for-new-selves.md), [tone shifting](../../frameworks/tone-shifting.md)).
  - **DON'T** fabricate proof, scarcity or testimonials. The course flags this repeatedly.
- **See also:** [AGENTS.md](../../../AGENTS.md), [playbooks](../../playbooks/), [libraries](../../libraries/), [prompt library](07-prompt-library/README.md).

## The Tether Lab model in one table

| Lens | Question to ask of any ad | Values | Page |
|---|---|---|---|
| Brain | Is it talking to the fast subconscious or the slow conscious mind? | subconscious ≫ conscious | [two minds](../../concepts/subconscious-vs-conscious-mind.md) |
| Heuristics | Which shortcuts does it trigger, and are they stacked well? | 9 core + ~40 more | [heuristics hub](../../concepts/heuristics.md), [stacking](../../concepts/heuristic-stacking.md) |
| Emotion | Where does it sit on valence × intensity? Does that match the market? | Zones 1–4 | [emotional zones](../../concepts/emotional-zones.md) |
| Identity | Which self does it speak to? | Actual / Ideal / Ought | [three selves](../../concepts/three-selves.md) |
| Journey | Which buying stage is it written for? | Trigger / Exploration / Evaluation / Purchase | [TEEP](../../frameworks/teep-journey.md) |
| Behavior | Is motivation, ability or the prompt the bottleneck? | B = MAP | [Fogg model](../../frameworks/fogg-behavior-model.md) |

## Learning path (from the course)
1. Watch the welcome tour, then do **Heuristics 101 → Valence & Intensity → Self Targeting** in order.
2. Use the **Prompt Library** and toolkit while building ads.
3. Bring ads to **Roast My Ads** and questions to **Live With Sarah!**
