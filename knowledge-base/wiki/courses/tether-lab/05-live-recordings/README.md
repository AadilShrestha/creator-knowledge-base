# Module 5: Live Recordings (May–July 2025)
> 16 recorded community calls, about 16 hours in total: weekly **Live With Sarah!** Q&As, monthly **Roast My Ads** (members' real ads and pages critiqued), and two **guest sessions**. Most of the course's real-world ad teardowns are in this module.

## 🤖 Agent use
- **Use when:** you need *applied* judgement: how Sarah critiques a real ad, what she'd change, and the reasoning behind it. Start with the **Roast My Ads** pages to calibrate your own teardowns; use the Q&As for edge cases (luxury, B2B, high ticket, subscriptions, bundles, insurance, Gen Z, multi-brand stores).
- **Inputs → outputs:** competitor ad or our draft → find the closest critiqued example (see [brands index](../../../brands/README.md)) → apply the same diagnosis and fix.
- **Rules:**
  - **DO** treat each teardown row as a precedent: same niche + same failure → same fix.
  - **DO** check the date. Advice evolves (e.g. TEEP structure differs between [May 21](2025-05-21-live-with-sarah.md) and [June 4](2025-06-04-live-with-sarah.md)); see [TEEP journey](../../../frameworks/teep-journey.md).
  - **DON'T** quote Sarah's uncited statistics as fact in ads. The pages flag them.
- **See also:** [libraries](../../../libraries/), [creative testing system](../../../frameworks/creative-testing-system.md), [landing page audit](../../../frameworks/landing-page-psychology-audit.md).
