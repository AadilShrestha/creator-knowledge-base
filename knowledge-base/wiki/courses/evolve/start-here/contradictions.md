# Evolve Start Here: contradictions and agent defaults
> Where the 175 Start Here lessons disagree with each other, and where they disagree with Evolve Copywriting and Tether Lab. Each row cites both sides and gives the **default an agent should follow**. Rows come from the conflicts logged while the course's concepts, frameworks, playbooks, rubrics and libraries were written, with duplicates merged.

## 🤖 Agent use
- **Use when:** two Start Here pages give different numbers or rules, or before you put a budget, test length, spend-share bar, scaling step, creator rate or avatar count into a plan.
- **Inputs → outputs:** a conflicting instruction plus the account's context (monthly revenue, daily spend, margin) → the default to apply, the pages that already apply it, and what to test if it matters.
- **Rules:**
  - **DO** follow the "Agent default" column unless the brand's context or the user says otherwise. Name the default you applied and its row.
  - **DO** read spend-dependent rows against the account's real daily spend and monthly revenue. Most conflicts here are two instructors speaking to different account sizes, or a recording that the lesson page text later corrects.
  - **DO** prefer the lesson page text over the audio when a row says the page corrects the video (7-day tests in L94, the L171 sophistication note).
  - **DO** treat every number as an instructor rule of thumb (instructor claim), not a measured benchmark. Breakthrough and tier figures rest on small samples (see [KPI thresholds](libraries/kpi-thresholds.md), coverage and gaps).
  - **DON'T** resolve a conflict by ripping creative, inventing proof or reusing someone else's health claim. Rows marked ⛔ are course tactics that must not be executed.
- **See also:** [course hub](README.md) · [KPI thresholds (conflicting values side by side)](libraries/kpi-thresholds.md) · [rules library (conflicts at a glance)](libraries/rules.md) · [Evolve Copywriting contradictions](../copywriting/contradictions.md) · [global contradictions](../../../contradictions.md)
