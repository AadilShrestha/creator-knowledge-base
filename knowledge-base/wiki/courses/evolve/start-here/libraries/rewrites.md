# Rewrites library (Evolve Start Here)
> Every before → after change shown in the Start Here lessons (71 rows from 72 harvested), from single headline edits to the full MetaGlow script rebuild, grouped by the lever that changed so an agent can make the smallest fix that solves the problem.

## 🤖 Agent use
- **Use when:** a hook, static headline, hold, body section or CTA is weak; turning a loser or near-winner into the next iteration; turning raw research (Reddit quotes, objections) into usable copy; cleaning up a planning sheet entry.
- **Inputs → outputs:** the weak line or record + what's wrong with it (generic? wrong awareness? too intense? no mechanism? no avatar?) → the matching lever section → 1–3 precedent rows → one changed lever applied to our line, tested as a variation.
- **Rules:**
  - **DO** change one lever per variation and say which (specificity, desire, awareness, mechanism, intensity, format, avatar), so the test teaches something. [L067 01:56](../lessons/067-action-item-find-new-mechanisms.md) [L131 04:10–05:05](../lessons/131-how-to-do-iterations-variations-live-example.md)
  - **DO** move generic outcomes to a specific, visual pain ("Lose the muffin top for good"). [L006 10:17](../lessons/006-13-winning-static-ad-templates.md) [L088 11:24](../lessons/088-the-execution-problem.md)
  - **DO** put the blame shift and the problem explanation before the product, then add a mechanism and an analogy. [L130 43:30–48:04](../lessons/130-how-to-rewrite-losing-ads-into-winners.md)
  - **DO** write learnings about the customer ("behaviors/desires/experiences to go deeper on"), not about the ad ("this headline sucks"). [L082 13:50](../lessons/082-the-3-testing-methods-part-2.md)
  - **DON'T** keep fear-mongering stats; dial intensity down until the claim is defensible ("that is as far as I would like to go"). [L068 16:48–17:54](../lessons/068-how-to-find-apply-new-information-part-3.md)
  - **DON'T** admit a flaw in the ad when a guarantee covers it; lead with the risk reversal. [L036 00:00–00:56](../lessons/036-competitor-research-part-2.md)
  - **DON'T** reuse the "after" text verbatim for our brand; the claims inside (56%, 99.99%, $2,000,000) belong to those brands. Copy the move, not the line.
  - **IF** a static wins **THEN** try the same angle in a new format and with a narrower avatar before inventing a new angle (static $10K/week → AI-VO story video for parents, $80K/week at the same ROAS; instructor claim). [L082 17:59–19:48](../lessons/082-the-3-testing-methods-part-2.md)
  - **IF** a hook is a command ("Stop scrolling") **THEN** replace it with a reason plus payoff. [L088 20:36](../lessons/088-the-execution-problem.md)

## Which lever for which problem
| IF the line or ad… | THEN use lever | Start with |
|---|---|---|
| Is vague or abstract ("lose weight", "doesn't rip") | Specific, visual pain | W001, W021 |
| Uses jargon ("metabolic gummies") | Specific, visual pain (plain words) | W002 |
| Is a bare claim static ("World's first…") | Belief and proof → one reason per concern, then a new format | W030, W043 |
| Names a problem the audience doesn't feel | Awareness | W016, W018 |
| Contradicts what the market believes | Counter-market opener | W019 |
| Asserts the product works without saying how | Mechanism | W023, W027, W028, W029 |
| Scares with a big stat | Intensity down | W031, W032 |
| Has a generic hold or feature-list body | Specific scene / experience | W005, W006 |
| Targets a demographic | Avatar and targeting | W051, W053 |
| Planning sheet says "test UGC" with no reason | Planning records | W060, W064, W066 |
