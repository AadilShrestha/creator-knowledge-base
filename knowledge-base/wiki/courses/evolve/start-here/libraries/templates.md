# Templates library (Evolve Start Here)
> Every fill-in structure in the Start Here lessons (74 templates): hook and belief formulas, script sequences, static layouts, research-doc fields, naming conventions, budget-move notes and the creator-program messages, grouped by job and cited to lesson and timestamp.

## 🤖 Agent use
- **Use when:** you know which part of the job you're on (a hook, a belief section, a static, a research-doc field, an ad name, a creator message) and want the course's slot structure.
- **Inputs → outputs:** the job → the section below → the template → filled with **our** product facts, customer words and real proof → checked against [rules](rules.md) and, for numbers, [kpi-thresholds](kpi-thresholds.md).
- **Rules:**
  - **DO** fill slots from research (reviews, Reddit, objections), never from the example fill; the examples are other brands' facts.
  - **DO** run the belief devices in order of what the avatar doubts: yes-train when they need to self-select, symptom story when they doubt the problem, false-belief replacement when they believe the opposite, logic chain when they doubt the mechanism. [L016 08:08–15:30](../lessons/016-market-belief.md)
  - **DO** put the mechanism before the product in a script and name it ("problem with alternatives → one ingredient → only us"). [L130 43:30–48:54](../lessons/130-how-to-rewrite-losing-ads-into-winners.md)
  - **DO** use one naming convention for every campaign, ad set and ad so spend can be read by batch, concept, page, creator and editor. [L109 03:30](../lessons/109-how-to-set-up-naming-templates.md) [L095 frame 03:50](../lessons/095-how-to-test-landing-pages-3-2-2-2.md)
  - **DON'T** fill a "% of people" or social-proof slot with a number you can't source (repo rule).
  - **DON'T** reuse a template's exact wording when the course calls it used up ("I think I just got scammed"). [L126 00:53–07:46](../lessons/126-how-to-pull-frameworks-from-ads.md)
  - **IF** a creator isn't on revenue share **THEN** report soft metrics (thumbstop, hold, CTR, retention, shares, play time) instead of ROAS. [L160 05:09](../lessons/160-feedback-loops-with-your-brand-ambassadors.md)
- **See also:** [Hooks](hooks.md) · [Rewrites](rewrites.md) · [Prompts](prompts.md) · [KPI thresholds](kpi-thresholds.md) · [Campaign structure 3:2:2](../frameworks/campaign-structure-322.md) · [Insense creator pipeline](../frameworks/insense-creator-pipeline.md) · [Brand ambassador program](../frameworks/brand-ambassador-program.md) · [Market identification and belief](../concepts/market-identification-and-belief.md) · [Copywriting templates](../../copywriting/libraries/templates.md) (209 slot structures for hooks, bridges, pitches, stakes)
