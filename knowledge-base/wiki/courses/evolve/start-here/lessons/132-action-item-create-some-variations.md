# 132. Action Item - Create Some Variations
> A checkpoint after lessons 130–131: take one ad that got spend and make variations of it.

## 🤖 Agent use
- **Use when:** you have one ad or concept that spends or shows promise and need the next batch of variations.
- **Inputs → outputs:** one working ad plus its learnings card → a small set of variations that each change one element (derived from lessons 131 and 133).
- **Rules:**
  - **DO** treat this as the "do it now" step. The page says only "Don't just consume... Take action!".
  - **DON'T** assume the page defines how many variations or what to change; it does not. Use the rules from 131 and 133 and label them as such.

## How to apply (derived from lessons 131 and 133; not stated on the page)
- [ ] Choose the concept that is getting spend or has good soft metrics; check why it works (research, reviews, Reddit) [131].
- [ ] Make three variations of the concept, changing one element each. Priority from lesson 133: video hook/imagery, then headline/hook text, then hold/benefits, then persona.
- [ ] Keep the elements that you believe matter fixed (in lesson 131 the headline stayed, the imagery changed).
- [ ] Name the new ad set with a test number and concept, and note the variable ([094](094-how-to-set-up-a-3-2-2-campaign.md)).
- [ ] Log what you expected and what happened so the next round is informed.
