# 60. Action Item/ Complete Understanding Product Doc
> Homework: make your own copy of the Product Overview template, fill it out following lessons 57 to 59, and use the example doc (blinds, collagen, dog harness) as the reference for quality.

## 🤖 Agent use
- **Use when:** a brand needs its Product Overview completed before desire, sophistication and avatar work; checking whether a brand's product doc is complete.
- **Inputs → outputs:** product page, reviews, research doc, onboarding doc (if any) → a completed Product Overview doc, steps 1 to 7, with assumptions labelled.
- **Rules:**
  - **DO** work on a copy of the template, not the original. [Page text]
  - **DO** fill it "according to the video" (lessons [57](057-understanding-your-product-part-1.md), [58](058-understanding-your-product-part-2.md) manual, [59](059-understanding-your-product-part-3.md) with Claude). [Page text]
  - **DO** compare your output with the example doc, which holds three worked examples (blinds, collagen, dog harness). [Page text; doc]
  - **DON'T** present assumed benefits, desires or mechanisms as validated facts; the template labels them "Assumed". [Doc steps 4 to 6]
  - **DON'T** copy example details (names, stats, "patented", "68%") into a real brand's doc. [derived]
  - **IF** research exists (reviews, research doc, onboarding doc) **THEN** use the Claude-project route in [59](059-understanding-your-product-part-3.md) for the first draft and audit it. **IF** it does not **THEN** use the manual route in [58](058-understanding-your-product-part-2.md). [58 and 59 page text]

## Key ideas
- The page has no video. It says only: "Make a copy of the document below & fill it out according to the video", and links the template ("Product Document: (Make a Copy)") and the example doc ("Examples For Reference"). [Page text]
- The attached DOCX and the two linked Google Docs are the same files as in lesson 57: the blank template and the three-example doc. [Docs]
- What a completed doc must contain: product name and price, how the product works (plus a sixth-grade version), features, assumed benefits, assumed desires, new mechanisms (USPs), and four hidden-mechanism answers. [Doc]

## Steps / framework
| Step | Section | Done when |
|---|---|---|
| 1 | Basics | Product name and price point (with any struck-through price) filled |
| 2 | Product in Action | How it works, the outcome, and a 6th-grade version (check readability) |
| 3 | Features | Main features listed (a few or many) |
| 4 | Assumed Benefits | Every feature mapped to what it does for the customer |
| 5 | Assumed Desires | Every benefit mapped to the deeper "why does someone want/need that?" |
| 6 | New Mechanisms (USPs) | What is new vs the market, one or more |
| 7 | Hidden Mechanisms | Four prompts answered (see template) |

Product Overview Document
Purpose: Identify what EXACTLY your product is and does to identify desires, build avatars, and create winning ads.
Step 1: Basics

## How to apply
- [ ] Copy the template into the brand's working folder.
- [ ] Fill steps 1 to 3 from the product page and any spec sheet; note unknown materials or ingredients as unknown.
- [ ] Fill steps 4 and 5 as assumptions; ask "why?" for each benefit.
- [ ] Fill step 6 only with mechanisms that are actually different from the category; otherwise write "none confirmed".
- [ ] Answer the four step-7 prompts, including a casual friend-style explanation.
- [ ] Run the AI draft ([59](059-understanding-your-product-part-3.md)) or the manual pass ([58](058-understanding-your-product-part-2.md)) and audit against the example doc.
- [ ] Use the finished doc as an input to the desire work in [61](061-understanding-applying-desire-part-1.md).
