# 161. Action Item/ Complete Your Feedback Loops
> Build a shareable performance report for each creator and send it with commentary, using the process from lesson 160. Atria is recommended but not required.

## 🤖 Agent use
- **Use when:** creators have live ads and have not been told what is working.
- **Inputs → outputs:** ad names that contain each creator's name, performance data → one report per creator plus a short message or Loom saying what to repeat and what to fix.
- **Rules:**
  - **DO** run the lesson 160 process for every creator on the roster.
  - **DO** treat the tool as optional. Page text: "You of course don't 'need' it but it is an incredible way to visually communicate with creators and we highly recommend it if you are onboarding brand ambassadors".
  - **DON'T** skip the loop because you lack Atria. A Google Slides report, a Loom or plain notes also work. [160 05:09]
- **See also:** [160](160-feedback-loops-with-your-brand-ambassadors.md) · [41. Creative Research Part 1 (Atria)](041-creative-research-part-1-atria.md) · [123. How To Do Learnings Part 2](123-how-to-do-learnings-part-2-winning-ads.md)

## Key ideas
- The page says the tool used in lesson 160 is Atria (the page carries a sign-up link) and that it is optional but highly recommended for onboarding ambassadors. Nothing else.

## Steps / framework
(derived from 160)
1. Make sure every ad name contains the creator's name.
2. Create a custom report filtered on that name.
3. Choose which metrics to show or hide per [160](160-feedback-loops-with-your-brand-ambassadors.md).
4. Share the link with a Loom or notes.
5. Repeat monthly (lesson 156 promises a monthly report).

## How to apply
- [ ] One report per creator, filtered by ad name.
- [ ] Hide spend, ROAS and purchase value for creators not on revenue or ad-spend share.
- [ ] Send each creator the report with "repeat this / fix this" notes.
