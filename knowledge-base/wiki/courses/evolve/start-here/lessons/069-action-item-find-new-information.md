# 69. Action Item: Find New Information
> A no-video checklist page: run the New Information Finder Prompt (with the Market Sophistication doc attached) on your product, then verify and rewrite what comes back as taught in lesson 68.

## 🤖 Agent use
- **Use when:** you have your product name and URL and are ready to generate research-backed, educational hook ideas for a sophisticated market.
- **Inputs → outputs:** product name + product URL + Market Sophistication doc + the New Information Finder Prompt → "NEW INFORMATION RESEARCH FINDINGS" (source, why it's new, how to use ethically, 3 hooks per finding) → a verified, ethics-screened shortlist.
- **Rules:**
  - **DO** use the exact mini text prompt on this page with the product name and URL, with the finder prompt attached as "New Information Prompt". (Page text)
  - **DO** attach the Market Sophistication doc ("Market Sophistcation Document (Again)"). (Page text)
  - **DON'T** accept output unchecked; the instructor's standing rule (lesson 68 page text): "BE ETHICAL. DOUBLE CHECK YOUR FACTS. DOUBLE CHECK AI RESEARCH." See [68](068-how-to-find-apply-new-information-part-3.md).
  - **DON'T** ship low-valence, high-intensity hooks (fear); use the re-prompt in the templates section of [68](068-how-to-find-apply-new-information-part-3.md).
  - **IF** you cannot verify a finding at its source **THEN** discard it (derived).

## Steps / framework
1. Open the New Information Finder Prompt (Google Doc) and copy it. Its full verbatim text is in [68, "New Information Finder Prompt"](068-how-to-find-apply-new-information-part-3.md#new-information-finder-prompt).
2. Open the Market Sophistication doc (same doc as lesson 65; text and stage definitions in [65](065-understanding-market-sophistication-part-1.md)); export as PDF or attach.
3. In a fresh Claude chat send the Mini Text Prompt (below) with your product and URL, with both documents attached.
4. Review each finding's source and date; verify; run the valence/intensity screen; keep the hooks that educate and pique curiosity.

## How to apply
- [ ] Gather product name and URL.
- [ ] Attach the finder prompt and the Market Sophistication doc.
- [ ] Run, then verify every source and number yourself.
- [ ] Reject fear-based hooks; rewrite with lower intensity.
- [ ] Save approved findings to the brand's "New Information" list (see the desire template in [64](064-action-item-start-your-desire-hunt.md)).
- [ ] Turn the best finding into a concept and test it hook-first ([67](067-action-item-find-new-mechanisms.md)).
