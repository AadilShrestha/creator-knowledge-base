# 140. Action Item: Sign Up For Insense
> Buy the Insense brand plan using the Evolve discount and justify the cost with per-video maths: about $50 per video at 10 videos per month, down to $25 at 20.

## 🤖 Agent use
- **Use when:** budgeting creator sourcing, or deciding whether Insense is worth it for a brand.
- **Inputs → outputs:** plan cost + expected videos per month → cost per video.
- **Rules:**
  - **DO** sign up for the **brand plan**; the trial plan no longer includes product seeding ([138](138-ugc-content-overview-part-1.md)).
  - **DO** use the Evolve-only code **EASYA100** ($100 off; "you can not find this discount anywhere else so keep it in the community") via the sign-up link on the page.
  - **DO** use the instructor's 3-month maths to judge value (below). Product cost and shipping are not in the maths (derived).
- **See also:** [138](138-ugc-content-overview-part-1.md) · [139](139-ugc-content-overview-part-2.md) · [141. How To Add a New Brand To Insense](141-how-to-add-a-new-brand-to-insense.md)

## Page content (the only source)
- Code and link: "**EVOLVE Students ONLY can save $100 with code: EASYA100**" with the fas.st sign-up link (see source file).
- **The Math Over the next 3 months**

| Item | Value |
|---|---|
| Insense cost | **$1,500 = $500 per month** |
| 10 UGC videos per month | $500 / 10 = **$50 per video** |
| 15 UGC videos per month | $500 / 15 = **$33.33 per video** |
| 20 UGC videos per month | $500 / 20 = **$25 per video** |

- "TLDR; you can pay $1,500 to get access to videos from creators for as low as $50 per video through product seeding + you can find a brand ambassador who can print money for your business." (instructor claim)

## Steps / framework
1. Open the sign-up link; choose the brand plan; enter EASYA100.
2. Model cost per video = (plan cost per month) / (videos received per month). (derived)
3. Then add a brand ([141](141-how-to-add-a-new-brand-to-insense.md)) and launch a campaign ([143](143-how-to-create-an-insense-campaign.md)).

## How to apply
- [ ] Sign up with the code; screenshot the plan and monthly cost.
- [ ] Record expected videos per month to compare against the table above.
- [ ] Add product cost, shipping and any paid-creator credits (+10% fee, [139](139-ugc-content-overview-part-2.md)) to the true cost per video (derived).
