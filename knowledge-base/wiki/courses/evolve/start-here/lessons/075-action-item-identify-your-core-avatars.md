# 75. Action Item/ Identify Your Core Avatars
> Using the desires you already found, create and organise your own desire-based core avatars, following the live example in [74](074-how-to-build-core-avatars.md).

## 🤖 Agent use
- **Use when:** after the core-avatar walkthrough, for your own brand: converting a researched desire list into desire-based core avatars before building sub-avatars.
- **Inputs → outputs:** desires from the earlier "How to Create Avatar" steps (desire hunt, assumed desires, [63](063-how-to-find-desires-part-3.md), [64](064-action-item-start-your-desire-hunt.md)) → a list of desire-based core avatars, organised in your avatar/research doc.
- **Rules:**
  - **DO** start from the desires you found in the previous steps. (page text)
  - **DO** make them "Desire-Based Core Avatars" and organise them (page text); use the doc layout, scope/urgency/staying-power scoring and revenue-stage pick from [74](074-how-to-build-core-avatars.md) [12:01–19:55] (derived).
  - **DON'T** skip to sub-avatars before choosing your core avatar ([76](076-how-to-build-sub-avatars.md) [00:42–02:27]) (derived).
- **See also:** [74. How To Build Core Avatars](074-how-to-build-core-avatars.md) · [71. The Evolve Avatar Training](071-the-evolve-avatar-training.md) · [76. How To Build Sub Avatars](076-how-to-build-sub-avatars.md)

## Key ideas
- Page text in full: "**Time To Put Into Action** Leveraging the desires that you found in the previous steps in the How to Create Avatar series. It's now time to start creating and organizing some of your Desire-Based Core Avatars."
- The page gives no template, count, or deadline. The method comes from lesson [74](074-how-to-build-core-avatars.md) (and the Core 5 rules in [71](071-the-evolve-avatar-training.md)): one core avatar for $0–100K/month brands, a few more at higher revenue ([74](074-how-to-build-core-avatars.md) [19:14–19:55]; [76](076-how-to-build-sub-avatars.md) [13:14–14:08]).

## Steps / framework
Derived from [74](074-how-to-build-core-avatars.md), not from this page:
1. List your assumed and researched desires.
2. Rewrite each as "Wants X" / "Person wants to …"; delete mega-broad ones. [74 02:33; 07:45]
3. Score scope, urgency, staying power. [74 15:10–19:55]
4. Pick by revenue stage; keep the rest parked in the doc. [74 19:14]

## How to apply
- [ ] Open your avatar doc; paste your desires from the desire hunt.
- [ ] Create a "Desire-Based Core Avatars" section with each desire as a core avatar.
- [ ] Mark your chosen core avatar; leave "Sub Avatar:" placeholders under it for [77](077-action-item-create-your-sub-avatars.md).
