# 77. Action Item/ Create Your Sub Avatars
> With one desire-based core avatar and your research in hand, build sub-avatars from the research; they are the raw material for relatable, customer-first ad angles in the next section.

## 🤖 Agent use
- **Use when:** you have one desire-based core avatar and research (Reddit, ad library, reviews) and need to produce the sub-avatars that angles will be built from.
- **Inputs → outputs:** one desire-based core avatar + customer research → a list of sub-avatars (each: desire + one or more of experience, emotion, behavior, demographic, plus a label), ready for the angle modules.
- **Rules:**
  - **DO** build sub-avatars "based on the research" once you have "identified one desire-based core avatar". (page text)
  - **DO** remember the purpose: sub-avatars "will be used to develop advertising angles that are actually relatable and customer-first". (page text)
  - **DO** follow the method in [76. How To Build Sub Avatars](076-how-to-build-sub-avatars.md): one desire, then layer product experience, experience, emotion, behavior, demographic (derived).
  - **IF** you finish **THEN** continue to the next section, "How To Make Ads (Execution)", for angles; the page links to it. (page text; [76](076-how-to-build-sub-avatars.md) page text)

## Steps / framework
Derived from [76](076-how-to-build-sub-avatars.md):
1. Confirm the core avatar has a real desire the product can deliver. [76 05:12–06:34]
2. Search the desire, emotion, behavior, demographic and product-experience terms on Google/Reddit. [76 09:58–13:14]
3. Record each finding as a sub-avatar record (desire + category fields + label). [76 31:40 doc]
4. Write a line or headline under each if you can. [76 17:31–19:42; 30:02]

## How to apply
- [ ] Open the avatar doc; under your chosen core avatar add Product-Experience, Experience, Emotion, Behavior and Demographic sub-avatar headings.
- [ ] Fill each with at least one researched sub-avatar (use real customer language).
- [ ] Add labels you found.
- [ ] Move on to angle-building in the next section.
