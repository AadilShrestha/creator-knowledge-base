# 73. Action Item/ Take a Breather
> After the dense Avatar Training module (lessons [71](071-the-evolve-avatar-training.md) and [72](072-evolve-avatar-training-ai-podcast-version.md)), stop, rest, then write 3-5 takeaways in a doc so they stick before building avatars in [74](074-how-to-build-core-avatars.md).

## 🤖 Agent use
- **Use when:** closing out a learning block before applying it: summarising what an agent (or human) learned from the Avatar Training before starting the build steps.
- **Inputs → outputs:** the Avatar Training content → a short list of 3-5 takeaways in a Google Doc or note page.
- **Rules:**
  - **DO** write 3-5 biggest takeaways before moving to the next session. (page text)
  - **DON'T** rush straight on. "Take a breather"; if you watched the entire lesson in one day, come back to the next module "tomorrow or later today". (page text)
  - **IF** you split the module across sessions **THEN** that is fine; still write the takeaways. (page text)
- **See also:** [72. Avatar Training (AI podcast)](072-evolve-avatar-training-ai-podcast-version.md) · [75. Identify Your Core Avatars](075-action-item-identify-your-core-avatars.md)

## Key ideas
- Tone of the page: "Time To Take 'Inaction' lol". "That module that you just watched was dense as hell." Eat, "touch some grass", do whatever you need. (page text)
- The one required task: "open up a Google Document or a note page and write down your 3-5 biggest takeaways so they STICK". (page text)
- Next step: "the next session, where we start to build out the avatars together" ([74. How To Build Core Avatars](074-how-to-build-core-avatars.md)). (page text)

## Examples
Takeaway examples given on the page (verbatim):
1. "The broader my avatar, the better everything else has to be."
2. "Desires are great for creating core avatars."
3. "Etc."

(These match the rules in [72](072-evolve-avatar-training-ai-podcast-version.md): broader avatar means the product, offer, brand and marketing must be stronger [06:36], and desires come first [06:36].)

## How to apply
- [ ] Pause after the Avatar Training; do not start building in the same sitting if you consumed all of it at once.
- [ ] Write 3-5 takeaways in a doc or note page (agent version, derived: append them to the project's avatar notes file).
- [ ] Proceed to [74. How To Build Core Avatars](074-how-to-build-core-avatars.md).
