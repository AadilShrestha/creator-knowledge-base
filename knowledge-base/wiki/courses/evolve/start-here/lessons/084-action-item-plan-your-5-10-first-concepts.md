# 84. Action Item / Plan Your 5-10 First Concepts
> After the planning modules, write down 5-10 concepts you want to test, then log them in the Growth Guide (next lessons).

## 🤖 Agent use
- **Use when:** the research, avatar and angle work is done and the next job is to produce the first test backlog for a brand.
- **Inputs → outputs:** desire-based core avatar, sub-avatars, angles ([76](076-how-to-build-sub-avatars.md), [77](077-action-item-create-your-sub-avatars.md), [79](079-how-to-come-up-with-ad-angles.md), [80](080-action-item-come-up-with-new-ad-angles.md)) → a written list of 5-10 concepts, each shaped as the concept card in [83](083-putting-all-the-planning-together-examples.md), ready to paste into the Ad Roadmap ([85](085-the-3-0-evolve-growth-guide.md), [86](086-action-item-make-a-copy-add-your-concepts.md)).
- **Rules:**
  - **DO** write down 5-10 concepts to test. (Page text: "write down 5-10 concepts that you want to test.")
  - **DO** organise them afterwards in the Growth Guide; the page points to the next module for how. (Page text.)
  - **DO** (derived) give each concept the same fields used in [83](083-putting-all-the-planning-together-examples.md): concept, concept explanation, angle(s) with sub-avatar, variations, format, testing method.
  - **DON'T** (derived) list formats alone ("UGC", "meme") without the angle they will carry; lesson 83 [24:48] asks "about what?"
- **See also:** [83. Putting All The Planning Together](083-putting-all-the-planning-together-examples.md) · [85. The 3.0 Evolve Growth Guide](085-the-3-0-evolve-growth-guide.md) · [Creative testing system](../../../../frameworks/creative-testing-system.md)

## Steps / framework
Steps are derived from lesson 83; the page itself gives only the count (5-10).
1. Pick the sub-avatar(s) and angle(s) from your earlier work.
2. For each, write the concept card (see [83](083-putting-all-the-planning-together-examples.md)): Concept, Concept Explanation, Angle(s) + sub-avatar, Variations, Format, Testing Method.
3. Choose Marksman (several angles, one variation each) for first image tests, Sniper for video ([83 §5](083-putting-all-the-planning-together-examples.md)).
4. Keep 2-4 creatives per test ([83 00:39](083-putting-all-the-planning-together-examples.md)).
5. Move the list into the Growth Guide Ad Roadmap ([85](085-the-3-0-evolve-growth-guide.md)).

## How to apply
- [ ] Produce a list of 5-10 concepts, each with an angle and sub-avatar attached.
- [ ] Mark each as Marksman or Sniper and give its format.
- [ ] Write the Why/What/How memo for the ones you will build first (see [85 §5](085-the-3-0-evolve-growth-guide.md)).
- [ ] Continue to [85](085-the-3-0-evolve-growth-guide.md) and [86](086-action-item-make-a-copy-add-your-concepts.md).
