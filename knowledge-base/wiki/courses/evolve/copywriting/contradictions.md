# Evolve Copywriting: contradictions and agent defaults
> Where this course disagrees with itself, and where it disagrees with Tether Lab (Sarah Levinger), each with the **default an agent should follow**. Logged while compiling the course's concepts, frameworks and playbooks; each row cites both sides.

## 🤖 Agent use
- **Use when:** two pages give different advice, or before you put a threshold (hook rate, budget, hook length, reading level) into a plan or script.
- **Inputs → outputs:** a conflicting instruction → the default to apply, plus what to test if it matters.
- **Rules:**
  - **DO** follow the "Agent default" column unless the brand context or the user says otherwise, and say which default you applied.
  - **DO** treat thresholds here as instructor rules of thumb, not measured benchmarks; none of them comes with published data.
  - **DON'T** resolve a conflict by inventing proof, scarcity or social-proof numbers. Honesty rules from both courses always win.
- **See also:** [global contradictions](../../../contradictions.md) · [course hub](README.md) · [Tether Lab hub](../../tether-lab/README.md)

"A" and "B" are the two sides as logged; the creator is named where the row is cross-course. Lesson links go to the evidence; shared paths are Tether Lab pages.
