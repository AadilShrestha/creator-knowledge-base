# 69. Action Item: Write Your Image Ad Briefs
> A no-video assignment: use the Master Document (and Creative OS) to put the image-ad process from lessons 67-68 into practice and write your own image-ad briefs, because "you can't get to 100K per day unless you take action and start WRITING ads."

## 🤖 Agent use
- **Use when:** an agent (or writer) has finished the image-ad lessons and must now produce real briefs for a product; as the checklist that wraps lessons [67](67-how-to-write-image-ads-part-1.md) and [68](68-how-to-write-image-ads-part-2.md).
- **Inputs → outputs:** a completed Master Document (product, research, avatars, angles/ideas, new information, new mechanisms) -> one or more image-ad concept briefs (concept, angle(s), testing method, format, variations) and built static ads.
- **Rules:**
  - **DO** start from the Master Document template so every brief is traceable to product, research and avatar quotes (Skool page: "Master Document Template (if you want it)").
  - **DO** put your own research into it before writing: desires, customer language snippets, a desire-based core avatar with its mechanism, sub-avatars with desire and quotes, ad ideas, new information, new mechanisms (docx template headings).
  - **DO** write briefs with the concept-and-brief template and the process shown in [67](67-how-to-write-image-ads-part-1.md): concept, angle, testing method, specific format, per-variation messaging and content. The brief template itself is not attached to this lesson; it is linked from lesson 67's page and reproduced there.
  - **DO** use the inspiration-to-headline method in [68](68-how-to-write-image-ads-part-2.md) when you lack ideas.
  - **DON'T** wait for perfect designs: the instructor's stance in lessons 67-68 is that "it's okay to have ugly ads" when the information is good. (See those lessons for timestamps.)
  - **(derived)** Where a static ad's headline and bullets map to a UGC video's hook and proof beats, the same brief fields apply to a video brief (see [70](70-how-to-write-video-ads-part-1.md)).
- **See also:** [67. How To Write Image Ads - Part 1](67-how-to-write-image-ads-part-1.md) · [68. ## How to apply
- [ ] Create the Master Document for the product and fill every tab.
- [ ] Write at least one concept brief per sub-avatar test following lesson 67's fields.
- [ ] Build the first static ad per brief; use Creative OS or the template deck for the layout (lesson 68).
- [ ] Review after a break; fix claims and numbers before testing.
- [ ] Log the angle (reason to buy) next to every concept before shipping.
