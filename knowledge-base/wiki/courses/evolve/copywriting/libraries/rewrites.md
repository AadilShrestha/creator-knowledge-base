# Rewrites library (Evolve Copywriting)
> Every before → after rewrite in the Evolve Copywriting course, merged across lessons and grouped by the one lever that changed: visual, falsifiable, ownable, fluff cut, label, stakes, urgency, show-don't-tell, comparison, objection, authority, hook form, valence, awareness, story, offer, funnel, format, accuracy and slippery slope.

## 🤖 Agent use
- **Use when:** a line, hook, bridge, bullet or CTA is weak and you want the smallest change that fixes it; when building a controlled iteration of a winner (one lever per variant); when explaining why a competitor's version beats ours.
- **Inputs → outputs:** the weak line + the diagnosis (which check it fails: [3 checks](../concepts/three-copy-checks.md), stakes, belief, issue code) → the matching lever section → 2–3 precedent pairs → our rewrite using the same move with our facts.
- **Rules:**
  - **DO** name the lever before rewriting, and change one lever per variant when testing, so the result is readable; label every change you make ("Changes Made"). [L54 08:49](../lessons/54-iteration-examples-breakdowns-walkthrough.md) [L46 13:34](../lessons/46-the-10-step-iteration-process.md)
  - **DO** keep what the original line communicates; a rewrite that keeps the facts but changes the feeling "makes no sense", and a variation that changes the feeling is a different ad. [L09 08:49-09:37](../lessons/09-the-importance-of-how-you-say-it.md)
  - **DO** make every "after" true for our product: no invented authority story, statistic, sell-out count or review volume. "Always take the facts and tell the truth." [L52 02:19](../lessons/52-the-iteration-playbook-script.md) [L70 docx, Borrowed Proof Protocol](../lessons/70-how-to-write-video-ads-part-1.md)
  - **DON'T** stack levers on a spend winner by changing format first; fix belief, urgency, stakes and congruence in the same format. [L50 17:18](../lessons/50-how-to-iterate-on-spend-winners.md)
  - **IF** the before is an opinion **THEN** try §2 (fact) first; **IF** it's abstract **THEN** §1/§8; **IF** it's true but flat **THEN** §6 (stakes). [L10 01:06](../lessons/10-why-you-need-to-write-facts.md) [L08 03:06-04:01](../lessons/08-the-3-checks-for-great-copywriting.md) [L30 01:27-02:26](../lessons/30-how-to-raise-the-stakes.md)
