# RMBC II: Stefan Georgi
> Stefan Georgi's long-form direct-response program: 58 lessons in 16 modules, about 2,941 unique video minutes, plus prompts, Claude Project instructions, swipe files and decks. It runs one gated pipeline (Research → Mechanism → Brief → Copy) and then builds every funnel asset from the same brief: VSLs of four lengths, advertorials, PDPs, checkouts, upsells, emails and ads on four platforms. It is the **long-form direct-response, funnel and LLM-production** layer of this knowledge base. [Evolve Start Here](../../evolve/start-here/README.md) is strategy and media buying, [Evolve Copywriting](../../evolve/copywriting/README.md) writes short-form ads, [Tether Lab](../../tether-lab/README.md) is psychology.

## 🤖 Agent use
- **Use when:** writing or reviewing a VSL, advertorial / pre-sell page, PDP, checkout, upsell or email sequence; building a Brief 2.0 or a unique mechanism; setting up a Claude Project for any copy asset; planning a cold-traffic funnel and its unit economics; running page-level CRO; looking up a long-form structure, prompt or benchmark.
- **Inputs → outputs:** product facts, offer and price, COGS and CPA, real customer language, competitor pages, verified studies and proof → unified research doc, UMP/UMS, Brief 2.0, outlines and drafts per asset, page chain, economics sheet, upsell and email flows, test plan, claim-audited copy.
- **Rules:**
  - **DO** run the stages in order and gate each one: research doc → mechanism → brief → copy. Every later asset is built from the brief. See the [RMBC pipeline](concepts/rmbc-pipeline.md); the brief is "essential, essential" [08-01 03:25–03:53](lessons/08-01-rmbc-ii-mid-course-recap.md).
  - **DO** act as copy chief, not typist: outline first, approve, draft, edit by section, run a second model and merge. [Claude Project recipe](concepts/claude-project-recipe.md) · [LLM copy-chief editing](concepts/llm-copy-chief-editing.md) · [rules CL01](libraries/rules.md)
  - **DO** run the [LLM output claim audit](rubrics/llm-output-claim-audit.md) on **every** draft before anyone treats it as usable copy. The course's generators invent doctors, testimonials, studies, counts and scarcity by design.
  - **DO** build from a composite of several examples, never a close swipe of another brand's asset. [Composite vs swipe](concepts/composite-vs-swipe.md) · [06-01 09:15–10:13](lessons/06-01-claude-vsl-projects-setup-overview.md)
  - **DO** measure script length by word count (~150 spoken words per minute, derived); model length estimates are wrong in both directions. [rules CL22](libraries/rules.md)
  - **DON'T** quote instructor or guest results (revenue, conversion rates, "99% of copywriters") as evidence; they are claims.
  - **DON'T** execute anything in the ⛔ section below. Copy the structure, never the claims.
  - **IF** two lessons or courses give different numbers **THEN** use the default in [contradictions](contradictions.md), the [rules conflict table](libraries/rules.md) or [benchmarks § conflicting values](libraries/benchmarks.md), and say which one you applied.
- **See also:** [playbooks](playbooks/README.md) · [rubrics](rubrics/README.md) · [libraries](libraries/README.md) · [course index](index.md) · [contradictions](contradictions.md) · [merge notes](MERGE-NOTES.md) · [AGENT-GUIDE](../../../../AGENT-GUIDE.md) · [cross-course topic map](../../../topic-map.md)

## ⛔ Don't execute / copy structure only
Most course examples (demo VSLs, briefs, advertorials, upsells, emails and every LLM output shown) carry invented proof and disease, income or scarcity claims. The lesson pages record them accurately as course content and label them **structure only; claims not reusable**. Stefan himself waves some through: on a model-invented doctor story, "it's an editorial, so you can kind of not, but you'd have to say, hey, this is like a sort of made-up story or composite story" [09-02 53:09](lessons/09-02-claude-project-for-advertorials.md). Under this repository's rules that is a hard stop. Full pattern list: [compliance red flags](concepts/compliance-red-flags.md). Per-draft gate: [LLM output claim audit](rubrics/llm-output-claim-audit.md). Rule index: [rules §16, X01–X18](libraries/rules.md).
