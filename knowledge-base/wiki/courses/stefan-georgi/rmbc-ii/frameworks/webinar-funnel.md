# Webinar Funnel
> For coaching, course, B2B-service or other $700–$6K offers: minimal registration page, indoctrination on the confirmation page, a calendar-add + email/SMS reminder cadence, a 60–90 minute education-led session (intro ~8 min, three belief-breaking "secrets" ~30–40 min, close ~15–30 min with bridge, stack, price, link, bonuses, financing, FAQs, all done by 1:15), a short order page, upsell and mandatory onboarding call, tracked against opt-in, show and close KPIs.

## 🤖 Agent use
- **Use when:** planning, writing or auditing a live/recorded webinar funnel instead of a VSL; writing the slide outline and close scripts; setting KPI targets; deciding whether a webinar fits the offer at all.
- **Inputs → outputs:** offer, price, avatar, host story, three beliefs the offer must break, real proof (testimonials, results, with consent), real bonuses and real deadlines, financing options → fit decision → funnel map → registration + confirmation page copy → reminder cadence → slide outline with scripts → KPI card → test plan.
- **Rules (guest claims, Dylan Vanas, unless marked):**
  - **DO** make it education-based: "webinars are education-based. VSLs are intrigue-based." Teach "the what, not the how" [16-04 v2 14:36–15:14, 45:13](../lessons/16-04-webinars-live-talk.md).
  - **DO** keep the registration page to headline, sub-headline, date, host info: "Don't put a video. Don't put testimonials." [16-04 v2 15:45–16:45](../lessons/16-04-webinars-live-talk.md)
  - **DO** judge the registration page on mobile; most visitors only ever see mobile (Stefan, 10-02) [10-02 20:30](../lessons/10-02-in-depth-case-studies-dr-clean-and-calvin-tran.md).
  - **DO** finish price and CTA "by at least an hour and 15 minutes" [16-04 v2 37:34, 55:23](../lessons/16-04-webinars-live-talk.md).
  - **DO** keep the order page short: "No one's getting sold by the copy on this page. They got sold by the webinar." [16-04 v2 20:57–21:25](../lessons/16-04-webinars-live-talk.md)
  - **DON'T** use the "we broke the internet, here's the new link" SMS; it is a fabricated outage (hard stop under repo rules) [16-04 v2 17:20–17:51](../lessons/16-04-webinars-live-talk.md).
  - **DON'T** use the staged price-drop story ("my wife said… charge $1,997") or reference prices never charged; income claims need substantiation and typical-results disclosure [16-04 compliance flags](../lessons/16-04-webinars-live-talk.md). See [compliance red flags](../concepts/compliance-red-flags.md).
  - **IF** physical DTC product **THEN** treat webinars as untested: "We haven't really got a chance to test with many products." [16-04 v2 1:01:11–1:01:40](../lessons/16-04-webinars-live-talk.md)
- **See also:** [funnel selection matrix](../concepts/funnel-selection-matrix.md) · [funnel economics](../concepts/funnel-economics.md) · [classic VSL structure](../concepts/classic-vsl-structure.md) · [vsl build with claude](vsl-build-with-claude.md) · [upsell flow build](upsell-flow-build.md) · [email sequences](email-sequences.md) · [paid traffic by platform](paid-traffic-by-platform.md) · [cro testing](cro-testing.md) · Evolve [bridges](../../../evolve/copywriting/concepts/bridges.md) · [beliefs](../../../evolve/copywriting/concepts/beliefs.md) · [pitch transition](../../../evolve/copywriting/concepts/pitch-transition.md)

## Procedure

### Step 1. Fit check
- **Input:** price, offer type, LTV, awareness. **Output:** webinar yes / no / test.
- 13-01 matrix: "$1k-$3k: long webinar, application call, multi-email indoctrination"; heavy funnels (score ≤25) run "Ad → possible story presell → 35-45 min VSL/webinar → application/checkout" [13-01 16:12, doc](../lessons/13-01-hidden-factors-for-optimal-funnel-structure.md). High LTV supports "nurture webinar/mini-class funnels" [13-01 27:51](../lessons/13-01-hidden-factors-for-optimal-funnel-structure.md). Score with the [funnel selection matrix](../concepts/funnel-selection-matrix.md).
- Guest's range: $700 to $6K; coaching, courses, local dealerships, B2B warranty, CPAs, MSP-style contracts [16-04 v2 22:30, 1:01:11](../lessons/16-04-webinars-live-talk.md).
- Guest's case for webinars over VSLs (instructor claims, "paper napkin math" only [v2 18:22]): ~95% retention to CTA vs ~20% on a VSL; attendees pre-commit calendar time; live chat feedback lets you "split test every week" [16-04 v2 13:05–14:36](../lessons/16-04-webinars-live-talk.md). Compare the VSL engagement data in [vsl length bands](../concepts/vsl-length-bands.md) before believing the gap.

### Step 2. Map the funnel
Order (guest slide) [16-04 v2 15:14](../lessons/16-04-webinars-live-talk.md):
```
Traffic → Simple registration page → (optional self-liquidating offer) → Detailed confirmation page → Webinar → Order page → Upsell / order bump → Order confirmation (onboarding call booking)
            └→ Email + SMS reminder sequence
```

| Stage | Input | Output / rule | Source |
|---|---|---|---|
| Traffic | Offer, host, proof | 15–20 creatives + copy = 50–100 variations; ~$1,000 per ad set before judging | [16-04 v2 15:45, 31:44](../lessons/16-04-webinars-live-talk.md) |
| Registration page | Headline, sub-headline, date, host bio | No video, testimonials or complex forms | [16-04 v2 15:45–16:45](../lessons/16-04-webinars-live-talk.md) |
| SLO (optional) | $17–$49 product | Offered "if you want to come more prepared"; ~10% take → "roughly 20-30% liquidation" | [16-04 v2 18:22–19:25](../lessons/16-04-webinars-live-talk.md) |
| Confirmation page | Real proof, video, links | Confirmation video, calendar links, free community, testimonials, host info, socials | [16-04 v2 19:25–20:28](../lessons/16-04-webinars-live-talk.md) |
| Reminders | Event time | Daily emails; day before 2 emails + 2 SMS; day of 3 emails + 3 SMS (morning, 1 h before, "live now"); calendar-add button (~+3% show, claim) | [16-04 v2 16:45–17:20, 19:59](../lessons/16-04-webinars-live-talk.md) |
| Webinar | Slide outline (Step 4) | 60–90 min starter; up to 2.5 h advanced | [16-04 v2 37:34](../lessons/16-04-webinars-live-talk.md) |
| Order page | Offer | Timer (real only), value stack, deliverables | [16-04 v2 20:57–21:25](../lessons/16-04-webinars-live-talk.md) |
| Upsell | Low-ticket add-on | ~20% take on his upsell (claim) | [16-04 v2 23:01–23:30](../lessons/16-04-webinars-live-talk.md) |
| Order confirmation | Calendar | Mandatory onboarding call; 80–90% book (claim) | [16-04 v2 23:30–23:59](../lessons/16-04-webinars-live-talk.md) |
| Qualification | Form | "Create your account" survey routes qualified buyers to call booking | [16-04 v2 23:59–24:25](../lessons/16-04-webinars-live-talk.md) |

- **IF** cost per registration is high **THEN** add the SLO to recoup ad spend [16-04 v2 18:22](../lessons/16-04-webinars-live-talk.md).
- **IF** low-ticket buyers don't qualify for the high-ticket tier **THEN** add the qualification form [16-04 v2 23:59](../lessons/16-04-webinars-live-talk.md).
- Upsell and bump logic: [upsell flow build](upsell-flow-build.md), [checkout optimization](checkout-optimization.md). Post-event email: book-a-call abandon sequence in [email sequences](email-sequences.md).
- Cadence at scale: twice a week (Tue/Wed/Thu evening + Saturday 10 a.m. PST) [16-04 v2 25:48](../lessons/16-04-webinars-live-talk.md).

### Step 3. Write the registration page (mobile first)
- **Input:** offer promise, date/time, host bio. **Output:** registration copy + mobile screenshot.
- Calvin Tran pattern (Stefan, 10-02): one job, signup + show-up; fields first name, last name, email, phone; then text and email to maximise show-up; desktop and mobile carried different copy and only mobile mattered ("Nobody's ever seen this page besides me") [10-02 16:35–21:05](../lessons/10-02-in-depth-case-studies-dr-clean-and-calvin-tran.md).
- CTA visible above the fold or sticky on mobile [10-02 19:01](../lessons/10-02-in-depth-case-studies-dr-clean-and-calvin-tran.md).
- **IF** opt-in below target **THEN** "simplify the page and just make it shorter" [16-04 v2 16:17](../lessons/16-04-webinars-live-talk.md).
- Calvin's mobile page shows earnings screenshots ("Attendees get real results"); the guest says no testimonials on the registration page. **Default:** follow the guest; if testing proof, use only real, typical results with disclosures [10-02 17:19–20:30](../lessons/10-02-in-depth-case-studies-dr-clean-and-calvin-tran.md).

### Step 4. Write the slide outline
Skeleton (derived from the guest's structure slide) [16-04 v2 55:25](../lessons/16-04-webinars-live-talk.md):
```
INTRO (about 8 min): Headline | Sub-headline | Hero's journey | Reverse authority | Hook till end (bonus) | Differentiator | Elephant in the room | Future pace
CONTENT (about 30-40 min): The what, not the how | Secret 1 (external belief) | Secret 2 (internal belief) | Secret 3 (mechanism belief) | proof under each | Recap
CLOSE (about 15-30 min): Bridge | Offer reveal | Value stack (proof + benefit per item) | Price drop | Link drop | 3-5 bonuses | Financing and payment plans | FAQs | Text-in CTA
```

**4a. Intro** [16-04 v2 38:34–43:42](../lessons/16-04-webinars-live-talk.md)
- Hero's journey (real story of the host).
- Reverse authority: "I'm nobody… But I figured this thing out. If I can, you can too." (story device; proof carries authority).
- Hook till end: a real bonus delivered at the end ("stick with me to the end… I'm going to give you…").
- Differentiator: take common industry speak and say "this is not that".
- Elephant in the room (verbatim script; skip if the host can't deliver it live) [16-04 v2 42:11–43:14](../lessons/16-04-webinars-live-talk.md):
```
All right, guys, look, I'm a big believer in no surprises, and so, you know, I just wanted to ask, like, who here is a little scared I might sell you something today? Go ahead and type one in the chat.

[chat reacts]

Well, hey, look, I got some good news for you. I'm going to sell you something here today. I'm going to give you an opportunity to join my community, but only for the people that get a ton of value from today's session. If that's fair, go ahead and say yes in the chat.
```
  Guest admits no controlled data; it "worked better" than hiding the sale [16-04 v2 44:14–45:13](../lessons/16-04-webinars-live-talk.md).
- Future pace: "Imagine six months from now when you have this…"

**4b. Content: three secrets** [16-04 v2 45:13–46:38](../lessons/16-04-webinars-live-talk.md)
- **Input:** the three beliefs blocking purchase. **Output:** one secret per belief.

| Belief type | Example phrasing (guest) | Secret's job |
|---|---|---|
| External | "it's saturated" | Show the opportunity is real now |
| Internal | "I'm not good enough" | Show the avatar can do it |
| Mechanism | "this won't work for me", "you could be a scammer" | Show why this method works |

- Each secret breaks a limiting belief and rebuilds it; seed what the product solves without saying "it's in the product"; proof under each secret (real only); recap at end [16-04 v2 46:09, 56:11–59:07](../lessons/16-04-webinars-live-talk.md).
- RMBC link: the mechanism belief maps to the UMP/UMS ([unique mechanism](../concepts/unique-mechanism.md)); room discussion: VSL teaching "here's the real reason for your problem" is the equivalent of rebuilding beliefs [16-04 v2 49:20–50:42](../lessons/16-04-webinars-live-talk.md).
- Optional: draft the belief list and secrets from the [unified research document](../concepts/unified-research-document.md) and [brief generator](brief-generator.md) output (derived).

**4c. Close** [16-04 v2 46:38–56:11](../lessons/16-04-webinars-live-talk.md) ("the most important part")
1. Bridge, two-options (verbatim):
```
Look, guys, you can go about your way, or you can take the information I shared with you for free today and go apply it. It might take you months, years, or you might never get there. Or option two, you can work with me and I'll share the exact system on how I was able to do X, Y and Z. Would it be okay with you guys if I shared how you could work with me? Type one in the chat.
```
   or information-alone (verbatim):
```
All right guys, we covered a lot today. Would you agree information alone is not going to save you? In fact, I don't care how many books you read, how many things you show up for, what is it that really creates the change in your life?
```
2. Offer reveal: "Would you be open to me sharing how you can get involved?… That's why I created [offer]."
3. Value stack: each item with detail, proof, benefits; avoid black-on-red cliché [16-04 v2 51:07–52:06](../lessons/16-04-webinars-live-talk.md). Item "values" must be defensible (derived).
4. Price drop: guest drops ~three times, last step ~25% [16-04 v2 52:06–53:10](../lessons/16-04-webinars-live-talk.md). **Compliant version (derived):** state the real standard price you charge, then the real event price and its real end; no invented story.
5. Link drop: chat link or in-platform offer; low first payment ("start for $1,200") [16-04 v2 52:06, 53:30](../lessons/16-04-webinars-live-talk.md).
6. 3–5 bonuses with real urgency (first N, or next 10 minutes, then actually removed) [16-04 v2 53:41–54:08](../lessons/16-04-webinars-live-talk.md).
7. Financing (verbatim), then ~8 min later split pay, then payment plans, each its own link [16-04 v2 54:08–55:19](../lessons/16-04-webinars-live-talk.md):
```
All right guys, I saw the chat, and I understand that for some of you, $2,000 isn't realistic. So we partnered up with a financing company. When you click the link, you'll see these options pop out. You guys can get started.
```
   **IF** offer > $1,000 **THEN** add Affirm/Klarna/Afterpay.
8. FAQs: pre-scripted objections answered live [16-04 v2 55:39](../lessons/16-04-webinars-live-talk.md).
9. Text-in CTA + chat closer (verbatim) [16-04 v2 1:02:32](../lessons/16-04-webinars-live-talk.md):
```
Working with us more closely is something you're interested in? Here's the phone number to text right now. Just message us the word [KEYWORD] and we'll get you the info.
```
   Claimed +3–4% live, +5% next day from VA follow-up (instructor claim).
- Compare the VSL close: [classic VSL structure](../concepts/classic-vsl-structure.md) and [04-06 VSL closes](../lessons/04-06-vsl-closes.md).
- Slides: change often, little text, mostly pictures [16-04 v2 40:18–40:48](../lessons/16-04-webinars-live-talk.md).

### Step 5. Set KPIs and the economics check
| Metric | Bad | Good | Great | Source |
|---|---|---|---|---|
| Opt-in, cold paid | < 30% | 30–35% | n/a | [16-04 v2 16:17](../lessons/16-04-webinars-live-talk.md) |
| Opt-in, warm | < 45% | 45–50% (slide 45–55%) | n/a | same |
| Show rate | 20% | 30% | 40% | [16-04 v2 17:51](../lessons/16-04-webinars-live-talk.md) |
| Close rate (of attendees) | 1–2% ("go to webinar school") | 6–10% | > 10% | [16-04 v2 21:25](../lessons/16-04-webinars-live-talk.md) |

All guest claims for coaching/biz-op/B2B; track our own. Economics walk (guest): 1,000 registrants → 400 show → ~40 buyers × $1,000 = ~$40,000 vs ~$15,000 ad cost (B2B) or ~$4,000 (B2C/biz-op) [16-04 v2 21:55–23:01](../lessons/16-04-webinars-live-talk.md). Re-run with our CPL, show and close rates in [funnel economics](../concepts/funnel-economics.md) (derived).

### Step 6. Run, diagnose, iterate
| IF | THEN | Source |
|---|---|---|
| Opt-in below target | Shorten/simplify the registration page | [16-04 v2 16:17](../lessons/16-04-webinars-live-talk.md) |
| Show rate low | Check calendar-add, 1-hour and "live now" reminders before touching the pitch | [16-04 Rules of thumb](../lessons/16-04-webinars-live-talk.md) |
| Close rate low with good show | Fix the close first: good close + weak rest beats weak close + perfect rest "significantly" | [16-04 v2 46:38–47:07](../lessons/16-04-webinars-live-talk.md) |
| CPL high | Test borrowed-authority creative (with consent) and SLO | [16-04 v2 34:55–35:35, 18:22](../lessons/16-04-webinars-live-talk.md) |
| Price objection in chat | Financing step, not later | [16-04 v2 54:08](../lessons/16-04-webinars-live-talk.md) |
| Live sessions | Change one element per week from chat feedback | [16-04 v2 14:05–14:36](../lessons/16-04-webinars-live-talk.md) |

- Creative testing: "our opinion doesn't matter"; even the room couldn't pick the winning ad [16-04 v2 31:44–34:55](../lessons/16-04-webinars-live-talk.md).
- Page tests: [cro testing](cro-testing.md) (the 16-01 guest swapped webinar software for +35% sales, guest claim) [16-01 1:09:31](../lessons/16-01-cro-with-4080-marketing.md).

## Failure modes

| Symptom | Cause | Fix | Source |
|---|---|---|---|
| Low opt-in | Video/testimonials/long form on registration page | Headline, sub-headline, date, host only | [16-04 v2 15:45–16:45](../lessons/16-04-webinars-live-talk.md) |
| Low show-up | No calendar-add, thin reminders | Full cadence + calendar button | [16-04 v2 16:45–17:20](../lessons/16-04-webinars-live-talk.md) |
| Angry chat at the pitch | Sale hidden until the end | Elephant-in-the-room script | [16-04 v2 44:14–45:13](../lessons/16-04-webinars-live-talk.md) |
| Viewers leave before offer | Pitch after 1:15 | Price + CTA by 1:15 | [16-04 v2 37:34](../lessons/16-04-webinars-live-talk.md) |
| Host "chickens out" at close | Close skipped/softened | Rehearse the bridge and stack | [16-04 v2 47:07](../lessons/16-04-webinars-live-talk.md) |
| Unqualified calls | No qualification step | "Create your account" form | [16-04 v2 23:59](../lessons/16-04-webinars-live-talk.md) |
| Desktop-only review | Mobile is the real page | Review on phone width | [10-02 19:01–20:30](../lessons/10-02-in-depth-case-studies-dr-clean-and-calvin-tran.md) |
| Regulatory risk | Income claims, fake outage SMS, staged price story, fake scarcity | Remove; real proof and real deadlines only | [16-04 compliance flags](../lessons/16-04-webinars-live-talk.md) |
