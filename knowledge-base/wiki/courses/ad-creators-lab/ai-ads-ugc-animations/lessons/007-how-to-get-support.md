# 7. How To Get Support
> How to get an answer fast: which live call owns which problem, and what a good community post contains.

## 🤖 Agent use
- **Use when:** you are stuck (model failing, credits, script, angle, edit) and want the right channel; also a template for any help request an agent writes.
- **Inputs → outputs:** problem type → call or post; post must carry four things.
- **Rules:**
  - **DO** write help requests with four items: what you are making, where you got to, what happened instead, what you already tried (page). "Miss one and you get a question back instead of an answer."
  - **DO** record a Loom (free screen + face recording) for complex problems: "collapses a twenty-message back-and-forth into one answer" (page) [00:00].
  - **DON'T** hold back a basic question: "no such thing as a dumb question" [00:00].
- **See also:** [Meet the team](004-meet-the-team.md) · [24H challenge](002-the-24h-challenge.md)

- Synchronous: live calls (calendar) [00:00]. Asynchronous: a community post, answered "any hour, by the room and the team" (page).
- Page's next step: finishing Start Here; if you reached Level 2, go to The Arena for free credits (prizes are the instructor's claim).

## Steps / framework
1. Pick the call from the table or write a post with the four items.
2. For anything visual or multi-step, attach a Loom.

## Prompts / templates (verbatim)
```text
What I'm making: <ad format and product>
Where I got to: <last step that worked>
What happened instead: <error / bad output, with screenshot or Loom>
What I already tried: <settings, prompts, tools>
```
