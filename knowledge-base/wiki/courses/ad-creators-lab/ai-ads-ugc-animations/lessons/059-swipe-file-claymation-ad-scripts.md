# 59. Swipe File - Claymation Ad Scripts
> Three full script docs (a fragrance body butter, a muscle supplement, a hangover supplement) in a script / on-screen text / visual table format that feeds the claymation image-prompt step; useful for structure, but two of them contain health and "better than steroids" claims that must not be copied.

## 🤖 Agent use
- **Use when:** you need a template for claymation or animated-object ad scripts (hook rows, body, CTA, one visual per line) or want hook patterns to remix.
- **Inputs → outputs:** the three docs below → pattern for writing your own script with a visual column per line → input for [54](054-prompts-frames-chatgpt.md) / [55](055-prompts-frames-poppy-method.md).
- **Rules:**
  - **DO** write scripts as `Speech/Audio | Text on screen | Visual`, with a separate visual (and reference-image note) per sentence.
  - **DO** write 5 hook variants per concept with a different on-screen hook text for each, then one body and one CTA (Primal muscle and NextDay docs).
  - **DO** reuse the structure: identity question → misconception → mechanism → product → risk-reversal CTA (NextDay: "not just hydration… acetaldehyde… DHM… take with your last drink… or money back").
  - **DON'T** copy claims. Both the muscle and hangover scripts assert physiological effects ("IGF-1 boost", "neutralises acetaldehyde", "wake up at least 50% better", "banned by WADA", "better than tren") with no evidence in the files; competitors' brand/scent names are used in the perfume script. Re-source or drop.
  - **DON'T** use real-person look-alikes or real-brand characters from visuals (reference images are needed; use your own).
  - **IF** a script line has a struck-through edit **THEN** the author weakened it (see "Edits visible in the source") and the weaker version is the one to keep.

Script layout used in all three:

| Block | What it contains | Example |
|---|---|---|
| Hook table (x5) | spoken hook, on-screen hook text, visual | "Is he really natty? 💉💉" |
| Body | 8-14 spoken lines, each with one visual | NextDay "acetaldehyde" scene sequence |
| CTA | "If you want it simple, take/get [Product]…" + guarantee | "If you want it simple, take NextDay with your last drink and wake up at least 50% better - or money back." |

### Rules
- **DO** pair every spoken sentence with one unambiguous visual (a nose; a stomach; a liver chased by a red particle).
- **DO** ask the identity questions before writing the hook (NextDay doc): outcome identity "I'm actually aging gracefully, and my body can still handle the things I used to handle 5 years ago."
- **DON'T** include banned-sport claims or "legal" framing for hormones in any ad you ship.
- **IF** a hook compares to another named product or brand **THEN** remove the name (trademark / comparative claim).

### Edits visible in the source (Primal muscle doc)
The doc contains strikethrough text that was replaced: "sends IGF-1 straight into your bloodstream" → "boosts IGF-1 levels"; "lifetime guarantee" → "90-day guarantee"; "they designed a form of IGF-1 that gets absorbed by that exact mechanism" and "packed it into this spray called 191XT" → rewritten. These show claim softening in progress; the surviving text is still unsubstantiated.
