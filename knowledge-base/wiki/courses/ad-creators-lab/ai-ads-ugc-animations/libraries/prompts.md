# Prompts library (Ad Creators Lab)
> Index of every verbatim prompt, prompt template, brief template and Claude skill in the 110 lessons: what it does, which tool it targets, where the full text lives, and whether it carries a compliance flag. The full text stays on the lesson page; this page only points to it.

## 🤖 Agent use
- **Use when:** you need a working prompt or skill for one pipeline step (research doc, script, hooks, image, video, voice, song, static, brief) and want to know which lesson holds the exact text.
- **Inputs → outputs:** the pipeline step and the target tool → the matching section below → a row → open the lesson link, copy the prompt **structure**, fill it with our product facts, our research and our references → run it → audit the output.
- **Rules:**
  - **DO** open the linked lesson and copy from there; this page holds excerpts only. Skills: [Seedance 2.0 UGC Ad Director](../lessons/020-claude-skill-seedance-2-0-ai-ugc.md#the-claude-skill-seedance-20-ugc-ad-director-skillmd-from-the-linked-drive-zip), [skeleton-ads](../lessons/037-install-skill-generate-script.md#the-skill-file-skeleton-ads-lesson-attachment-2-install-skill--generate-scriptmd-complete), [Crochet Ad Visuals](../lessons/045-claude-skill-setup-explanation.md#crochet-ad-visuals-skill-crochet-ad-visualsskillmd-in-the-lesson-zip-complete).
  - **DO** run every LLM-written script, hook or headline through the [claim audit](../../../stefan-georgi/rmbc-ii/rubrics/llm-output-claim-audit.md) before production; the course's own [Fact Check prompt](../lessons/070-full-static-ads-creation-process.md#repair-prompts-fact-check-key-persona-curiosity-gap) is a first pass, not a substitute.
  - **DO** swap every named brand, product, competitor and claim in an example prompt for our own verified facts; bracket anything unverified.
  - **DON'T** execute rows marked ⛔ as written. Use the compliant alternative in the Flags column.
  - **DON'T** reuse the product claims inside rows marked ⚠️ (scripts and prompts that embed efficacy, price, scarcity or "testimonial" lines). Reuse structure only.
  - **DON'T** quote or reconstruct prompts the course only links to (Super-Doc, custom GPT instructions, Poppy boards, the Mr. Paid Social repo). They are **not in the course files** (§I).
  - **IF** a prompt targets a model you don't have **THEN** keep the prompt anatomy and check model-specific limits in [tool-settings](tool-settings.md).
  - **IF** you are writing a UGC or video-ad script **THEN** start from the repo skill [write-ugc-script](../../../../../../.claude/skills/write-ugc-script/SKILL.md) and use these prompts for the AI-production steps after it.
- **See also:** [tool-settings](tool-settings.md) · [README](README.md) · [rules](rules.md) · [reference-first prompting](../concepts/reference-first-prompting.md) · [character consistency](../concepts/character-consistency.md) · [start/end-frame video](../concepts/start-end-frame-video.md) · [Claude Code ad operator](../frameworks/claude-code-ad-operator.md) · [animated ad pipeline](../frameworks/animated-ad-production-pipeline.md) · [static ads process](../frameworks/static-ads-process.md) · Evolve Start Here [prompts](../../../evolve/start-here/libraries/prompts.md) · Evolve Copywriting [prompts](../../../evolve/copywriting/libraries/prompts.md) · RMBC II [prompts](../../../stefan-georgi/rmbc-ii/libraries/prompts.md)

## Flags
| Flag | Meaning | What to do |
|---|---|---|
| ⛔ | The prompt or skill instructs a non-compliant tactic: a real stranger's photo or a real creator's face/voice, a swap on someone else's ad, a fake testimonial or AI "customer", a real artist imitation | Don't execute as written. Use the compliant alternative in the row |
| ⚠️ | The prompt or script embeds unsupported claims (efficacy, health, price, scarcity, "testimonial"), real brand or competitor names, or a result presented as proof | Reuse the structure only; replace every claim with a verified, bracketed fact |
| (derived) | Template written by the lesson page, not by the course | Treat as a KB aid, not course text |
| (spoken) | Near-verbatim from the transcript, not shown as text | Wording may differ slightly |
