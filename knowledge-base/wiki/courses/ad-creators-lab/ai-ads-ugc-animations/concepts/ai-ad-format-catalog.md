# AI ad format catalog
> One row per ad format the course teaches, with what it is, how it is built (lip-sync, voiceover + B-roll, or mix), who it suits, the awareness stage it fits, what it costs at recording, and the lessons and framework pages that teach it; pick the format after the script, because "the format… of the AI is not what wins an ad, it's a script" ([L86 33:46](../lessons/086-ad-psychology-with-howie-2026-08-12.md)).

## 🤖 Agent use
- **Use when:** choosing a format for a script or angle; diversifying a batch into genuinely different formats; routing to the right framework, playbook and lessons for production; estimating cost before generating.
- **Inputs → outputs:** finished script (or angle) + avatar (age band, platform habits) + awareness stage + product type and claim sensitivity + budget → one or two formats from the table, the framework/playbook to run, the compliance flags to clear first.
- **Rules:**
  - **DO** write and audit the script before choosing visuals: "decide the script first… visuals are a tool… but they are not the crux of your ad" (David, [L91 43:53](../lessons/091-special-guest-recordings-ai-office-hours-david.md)); then run [AI creator compliance](ai-creator-compliance.md).
  - **DO** classify any reference ad with one question, "is the character's mouth moving?": lip-sync, voiceover + B-roll, or mix ([L91 01:24–02:49](../lessons/091-special-guest-recordings-ai-office-hours-david.md)). Voiceover + B-roll is "90 percent easily" of AI ads David sees because it is easier ([L91 02:49](../lessons/091-special-guest-recordings-ai-office-hours-david.md)).
  - **DO** pick the format by the audience's schema, not by trend: nostalgia formats (claymation, knit/felt stop-motion) for 50+; skeleton for 20s–30s; meme split-screens only for Gen Z (Hao, [L86 31:10–33:12; 47:43](../lessons/086-ad-psychology-with-howie-2026-08-12.md)).
  - **DO** make a batch diverse by format, not by headline: comparison, product + text, news/unaware, problem-solution, notes-app for statics ([L8 02:43](../lessons/008-how-to-make-diversified-ads.md)); see [diversification vs variation](diversification-vs-variation.md).
  - **DON'T** use Arcads "Talking Actors" for realism: "typically you get those actors that look like AI"; use the Video section (Sora 2 Pro) instead ([L33 00:00](../lessons/033-sora-2-pro-hooks.md)).
  - **DON'T** force AI where the concept needs a real process or reaction: the course says challenge, testimonial, us-vs-them and similar human UGC concepts "are not really types of videos that AI can produce" ([L106 00:00](../lessons/106-ugc-concepts-that-print.md), instructor claim).
  - **IF** the product needs legible on-pack text in an animated frame **THEN** generate that frame with Nano Banana Pro, the rest with a cheaper model ([L62 02:31–03:21](../lessons/062-talking-objects-tutorial.md)).
  - **IF** you test any animated format **THEN** run the cheapest video model first and move up only for the final ([L39 00:58](../lessons/039-skeleton-generating-videos.md); [L56 05:07](../lessons/056-claymation-generating-videos-transitions.md); [L62 08:10–09:04](../lessons/062-talking-objects-tutorial.md)).
- **See also:** [AI creator compliance](ai-creator-compliance.md) · [Diversification vs variation](diversification-vs-variation.md) · [Animated ad production pipeline](../frameworks/animated-ad-production-pipeline.md) · [AI UGC Seedance workflow](../frameworks/ai-ugc-seedance-workflow.md) · [Static ads process](../frameworks/static-ads-process.md) · [Shared format variation ladder](../../../../frameworks/format-variation-ladder.md)

## Definition
A **format** here is the production treatment that carries a script: who or what is on screen (AI person, animated character, object, product, text), how speech is delivered (lip-sync, voiceover, song, none), and the visual style (phone UGC, podcast set, street interview, claymation, crochet, skeleton, Pixar-style 3D, static template). Format is separate from **angle** (the desire or belief the script targets) and from **concept** (the idea); one concept can ship in several formats.

Build types (David's taxonomy, [L91 01:24–03:57](../lessons/091-special-guest-recordings-ai-office-hours-david.md)):
| Build type | What moves | Production note | Source |
|---|---|---|---|
| Lip-sync | The character's mouth speaks the lines | Write the whole script, generate the whole voiceover in one pass, slice it, pass each slice + a start frame to the video model; "the fastest to make" because pacing per clip is guaranteed | [L91 49:12–52:51](../lessons/091-special-guest-recordings-ai-office-hours-david.md) |
| Voiceover + B-roll | No mouth movement; narration over cutaway shots | About 90% of AI ads David sees; the style skill he teaches covers only this visual layer | [L91 02:49; 05:14](../lessons/091-special-guest-recordings-ai-office-hours-david.md) |
| Mix | Lip-sync scenes with B-roll over them, or a green-screened talking character over continuous B-roll | Hides lip-sync weaknesses behind cutaways | [L91 02:49–03:57](../lessons/091-special-guest-recordings-ai-office-hours-david.md); [L31 03:48](../lessons/031-realistic-ai-ugc-rizz-model-editing-breakdown.md) |

## Why it matters
- Format lowers the "this is an ad" defence; it does not sell. Hao: "The format… is just to bypass the defense mechanism" ([L86 33:46](../lessons/086-ad-psychology-with-howie-2026-08-12.md)).
- Wrong format for the age band reads as an ad or as noise: knit and claymation "don't necessarily work well for a younger audience", while for 50+ the first thought is nostalgia ([L86 31:10–32:42](../lessons/086-ad-psychology-with-howie-2026-08-12.md)).
- Format is the cheapest real diversity lever under Meta's current delivery, per the course: near-identical ads get treated as one ([L8 01:01–01:56](../lessons/008-how-to-make-diversified-ads.md), instructor claim).
- Cost differs by an order of magnitude between formats and models (credits below); the course's default is to test cheap, finalise on the better model.

## How to use (steps)
1. Fix the script, angle and awareness stage first ([L95 00:43](../lessons/095-market-awareness-explained-in-180s.md)); run the claim audit.
2. Decide the build type: does the story need a face speaking (lip-sync), or can narration carry it (voiceover + B-roll)? Default to voiceover + B-roll unless the concept is a person's testimony-style monologue, a podcast or an interview.
3. Filter the table by avatar age and platform habits (Hao's schema rule) and by claim sensitivity (health and body products need extra review in every format).
4. Pick one primary format and one contrasting format for the batch (different look at a glance; see [diversification vs variation](diversification-vs-variation.md)).
5. Open the framework or playbook in the row; estimate credits from the cost column (values at recording, Aug–Sep 2026; they change).
6. Clear the row's compliance flag before generating anything.

## Common mistakes
- Choosing the trending format first and fitting the script to it. Hao: format only lowers the defence; the script sells ([L86 33:46](../lessons/086-ad-psychology-with-howie-2026-08-12.md)).
- Using muted claymation colours for a high-intensity emotion: "muted claymation colours may not carry intense emotion" ([L87 18:22–19:26](../lessons/087-ad-psychology-with-howie-2026-08-27.md)); test visuals in opposite emotional zones ([L87 18:22](../lessons/087-ad-psychology-with-howie-2026-08-27.md)).
- Treating a lip-sync talking head as enough: static talking heads lose viewers; add B-roll, split screens or graphics ([L88 Agent use](../lessons/088-ad-psychology-with-howie-2026-07-29.md)).
- Leaving a perfect "podcasty" AI narrator on a story ad; it breaks believability ([L84 27:34–28:27](../lessons/084-ad-roast-calls-2026-08-21.md)).
- Copying a format's example script with the format: every format row above carries example claims flagged in [AI creator compliance](ai-creator-compliance.md).
