# Animated AI ad production pipeline
> Every animated format in the course runs the same six stages: script (with one visual per voiceover line) → character bible + hero image → keyframes (start, and end when the state changes) → image-to-video between frames → designed voiceover (or song) → edit timed to the audio. The formats differ in the style lock, the frame-chaining rule, the cheap/final model pair and a few edit tricks. This page is the run sheet plus a comparison of the course's Claude skills and GPTs.

## 🤖 Agent use
- **Use when:** producing a skeleton, crochet, claymation, talking-object or Zack D-style (3D cartoon explainer) ad; choosing which course skill/GPT to run; deciding start-only vs start+end frames; budgeting generations.
- **Inputs → outputs:** claim-audited script + product photo + research avatar → VO line list → `vo.mp3` → shot list with frame type per line → hero + keyframes → one clip per line or per transition → edited 9:16 ad (1080×1920).
- **Rules:**
  - **DO** write the script before visuals and treat the voiceover as the master timeline: "the main drive of what our ad will become" [L90 05:06](../lessons/090-ai-editing-2026-08-18.md); visuals "are not the crux of your ad" [L91 43:53](../lessons/091-special-guest-recordings-ai-office-hours-david.md).
  - **DO** generate one hero/character image first and attach it to every later frame; "reference image 1, not the previous image" (skeleton skill, [L37](../lessons/037-install-skill-generate-script.md#prompts--templates-verbatim)); forgetting the character reference "didn't look as good" [L46 09:03](../lessons/046-script-visualisation-image-creation.md).
  - **DO** attach the product photo to every frame where the product appears (skeleton and crochet skills; forgotten once and redone [L46 08:14](../lessons/046-script-visualisation-image-creation.md)).
  - **DO** decide frame type per shot: Type A start only (self-contained motion), Type B start + end (state change; end frame = "FINAL LANDED" state), Type C start only (subtle motion); "Default to Type A when unsure" (crochet skill, [L45](../lessons/045-claude-skill-setup-explanation.md#prompts--templates-verbatim)).
  - **DO** keep video prompts to motion + one camera move + one action; never dialogue or text in prompts (skeleton skill Stage 4).
  - **DO** test on the cheapest model, finalise on the better one: Seedance 1.5 Pro → Kling [L39 00:58](../lessons/039-skeleton-generating-videos.md); [L56 05:07](../lessons/056-claymation-generating-videos-transitions.md); [L62 08:10–09:04](../lessons/062-talking-objects-tutorial.md).
  - **DO** expect 4–5 attempts per scene [L90 12:29](../lessons/090-ai-editing-2026-08-18.md) and review keyframes before paying for video (Loom review sub-agent, [resource](../../../../resources/ai-song-ad-pipeline-loom.md)).
  - **DON'T** burn captions, words or watermarks into generated images or clips; captions go in the editor (skeleton skill; Zack GPT "CAPTION KEYWORDS (added in edit, not image)" [L65](../lessons/065-script-to-prompt-generator.md#prompts--templates-verbatim)).
  - **DON'T** clone a real creator's voice (067 teaches cloning Zack D Films' voice from YouTube: **don't execute**) [L67 00:00](../lessons/067-zack-d-films-voice-clone-song.md); design the voice [L57](../lessons/057-claymation-generating-voice-over.md).
  - **IF** the skill cannot know a visual (a specific ad, garment, product) **THEN** supply a screenshot reference you have rights to [L40 00:57](../lessons/040-advanced-video-prompts.md).
- **See also:** [Start/end-frame video](../concepts/start-end-frame-video.md) · [Character consistency](../concepts/character-consistency.md) · [Reference-first prompting](../concepts/reference-first-prompting.md) · [AI ad format catalog](../concepts/ai-ad-format-catalog.md) · [Song-ad workflow](song-ad-workflow.md) · [AI post-production](ai-post-production.md) · [Claude Code ad operator](claude-code-ad-operator.md) · [Produce an animated AI ad](../playbooks/produce-an-animated-ai-ad.md) · [AI video QA checklist](../rubrics/ai-video-qa-checklist.md) · [Prompt library](../libraries/prompts.md)

## Frame chaining rules (resolve before generating)
| Need | Rule | Source |
|---|---|---|
| Character identity across shots | Reference the hero, not the previous image | skeleton skill ([L37](../lessons/037-install-skill-generate-script.md#prompts--templates-verbatim)) |
| Background continuity inside one scene | Reference the previous frame ("If I was to just reference the initial character, we might get some changes behind") | [L46 05:18](../lessons/046-script-visualisation-image-creation.md) |
| Transition between scenes | Start = scene N, end = scene N+1 | [L56 00:00–02:57](../lessons/056-claymation-generating-videos-transitions.md) |
| State change of one object | End frame = variation of start; "Only the state… has changed" | [L65](../lessons/065-script-to-prompt-generator.md#prompts--templates-verbatim) |
| Continuing an action | Last frame of clip → first frame of next; enhance first | [L90 12:29; 43:35](../lessons/090-ai-editing-2026-08-18.md) |
| Camera move through a space ending on a known still | Seedance 2.0 References: "Video starts inside [space]… Camera zooms through the room and ends up with image one." | [L40 00:00](../lessons/040-advanced-video-prompts.md) |
**Default:** attach both the hero (identity) and the previous frame (setting) when the tool accepts two references (derived).

## Failure → fix
| Symptom | Fix | Source |
|---|---|---|
| Looks realistic/CGI in crochet | Push "stop-motion diorama" framing harder | crochet skill Tips |
| Yarn hands broken | Simpler poses: standing, sitting, one-arm gestures | crochet skill §4.3 |
| Particle clouds look CGI | A handful of yarn-ball orbs; character reaction instead | crochet skill §4.4–4.6 |
| Seedance adds a song | Audio off; or Kling | [L39 01:28](../lessons/039-skeleton-generating-videos.md); [L56 05:07](../lessons/056-claymation-generating-videos-transitions.md) |
| Character changes between scenes | Edit from reference, don't regenerate from text | [L54 02:26](../lessons/054-prompts-frames-chatgpt.md) |
| Effects baked into the still you want to animate | Remove them in image edit, animate later | [L54 01:54](../lessons/054-prompts-frames-chatgpt.md) |
| Ingredient text unreadable | Nano Banana Pro + "make the ingredients sheet bigger and also fix the text" | [L62 03:21](../lessons/062-talking-objects-tutorial.md) |
| Talking line cut off | Shorten script or lengthen clip (8 → 10 s) | [L62 06:48–07:39](../lessons/062-talking-objects-tutorial.md) |
| Grid/background drifts | Restate the spec in the same GPT chat, regenerate | [L65 01:48](../lessons/065-script-to-prompt-generator.md) |

## Disagreements and defaults
- **Video model.** Kling 3.0 Pro "the best" for skeleton [L39 00:58](../lessons/039-skeleton-generating-videos.md); Seedance 1.5 beat Seedance 2.0 in crochet, Kling nicer [L46 09:03](../lessons/046-script-visualisation-image-creation.md); Kling final for claymation [L56 06:10](../lessons/056-claymation-generating-videos-transitions.md) vs Seedance over Kling for claymation because Kling drifts [L90 1:09:39](../lessons/090-ai-editing-2026-08-18.md); Veo 3.1 best lip-sync for talking objects [L62 07:39](../lessons/062-talking-objects-tutorial.md). All single tests. **Default:** same frames on Seedance 1.5 Pro (test) and Kling 3.0 Pro; add Seedance 2.0 if the format is claymation and Kling drifts; Veo for native lip-sync.
- **Image model.** Nano Banana 2 better than Pro for claymation [L54 00:55](../lessons/054-prompts-frames-chatgpt.md); [L55 02:17](../lessons/055-prompts-frames-poppy-method.md) vs Nano Banana Pro for realism (015/018/021) and GPT Image 2 for storyboards [L90 08:44](../lessons/090-ai-editing-2026-08-18.md). **Default:** stage- and style-specific, as in the format table.
- **"Cinematic".** Clay still prompts contain "cinematic macro composition" [L54](../lessons/054-prompts-frames-chatgpt.md#prompts--templates-verbatim); video suffix says "Non cinematic" [L56](../lessons/056-claymation-generating-videos-transitions.md); skeleton default style is "Bare-Bones Cinematic". **Default:** allowed in still-image composition for animated styles; banned in video prompts and in realistic UGC.
- **Reference the hero vs the previous frame:** see chaining table; both apply to different problems.
