# Tools hub
> Every tool, platform and software product mentioned in Tether Lab, grouped by **where it sits in the ad pipeline** (research → ideation → production → AI UGC → inspiration/ad libraries → analytics/testing → delivery). Tools with substance have their own page; thin mentions are documented in the tables below.

## 🤖 Agent use
- **Use when:** choosing a tool for a pipeline step, or checking what Sarah actually said about a tool before relying on it.
- **Inputs → outputs:** a pipeline step → the tool(s) used for it in the course, the rule that goes with each, and where it's cited.
- **Rules:**
  - DO treat LLM output as a draft: give it fences, give it real context, verify every claim ([ChatGPT](chatgpt.md)).
  - DO use ad-library age ("running 195 days", "Evergreen 90+ days") as a *hint*, not proof of a winner. Big brands can afford to leave ads on ([June 11 0:22:19–0:26:35](../courses/tether-lab/05-live-recordings/2025-06-11-live-with-sarah.md)); [CreativeOS](creativeos.md) uses 90+ days as its Evergreen signal.
  - DON'T use AI faces for trust brands ([AI UGC tools](ai-ugc-tools.md)). AI voices for narration are fine ([ElevenLabs](elevenlabs.md)).
  - DON'T treat tool roadmaps or claims from mid-2025 as current.
- **See also:** [Customer research stack](../frameworks/customer-research-stack.md) · [Creative testing system](../frameworks/creative-testing-system.md) · [Brands](../brands/README.md) · [People](../people/README.md)
