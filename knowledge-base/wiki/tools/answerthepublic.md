# AnswerThePublic
> Search-question tool (answerthepublic.com). Sarah uses it in **monthly market research** and, more distinctively, to **read how educated the market is**: the kinds of questions people type tell you whether to educate or to compete on offers ([June 4 0:25:00; 0:52:34–0:54:36](../courses/tether-lab/05-live-recordings/2025-06-04-live-with-sarah.md)).

## 🤖 Agent use
- **Use when:** before writing angles for a category, to decide how much education the ads need and which [TEEP](../frameworks/teep-journey.md) stage to aim at.
- **Inputs → outputs:** the top-level category keyword → a list of real questions → an education-level read (low / mid / high) → which stage and message type to lead with.
- **Rules:**
  - DO type the **top-level keyword** and read all the questions ([June 4 0:52:34](../courses/tether-lab/05-live-recordings/2025-06-04-live-with-sarah.md)).
  - IF most questions are basic ("what is X / how does it work / what does it taste like") THEN the market is low-educated: write top-of-funnel education and exploration ads.
  - IF questions name a specific ingredient or mechanism THEN the market is mid-educated: write evaluation-stage comparisons.
  - IF questions compare specific formulations THEN the market is highly educated: "I don't have to do any education, I actually just have to be the best at offers in this industry."
