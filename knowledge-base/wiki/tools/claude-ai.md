# Claude
> Anthropic's LLM. Sarah's **fallback when ChatGPT can't write good headlines or apply a heuristic well**: "Claude is really interesting because it's a very empathetic AI… much better at explaining things" ([July 2 0:30:29–0:31:29](../courses/tether-lab/05-live-recordings/2025-07-02-live-with-sarah.md)).

## 🤖 Agent use
- **Use when:** a ChatGPT draft of headlines, emotional copy or a heuristic application comes back flat; or you need an explanation of why a mechanism works (for a brief or a teardown note).
- **Inputs → outputs:** the same verbatim prompt + persona doc + ad you gave ChatGPT → an alternative draft to compare.
- **Rules:**
  - DO run the same prompt in both models when copy quality matters, then pick the better output ("Claude, do this better") ([July 2 0:30:29](../courses/tether-lab/05-live-recordings/2025-07-02-live-with-sarah.md)).
  - DO apply the same guardrails as for [ChatGPT](chatgpt.md): give fences (scores, frameworks), give a detailed persona doc, and verify every claim, stat and testimonial.
- **See also:** [ChatGPT](chatgpt.md) · [Tools hub](README.md)
