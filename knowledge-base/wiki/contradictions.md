# Contradictions & open questions
> Places where sources disagree (inside Tether Lab, and between Tether Lab and Evolve Copywriting), with the **default an agent should follow** and the reason. Check here whenever two pages give different advice.

## 🤖 Agent use
- **Use when:** two pages disagree, or before you put any number (batch size, scaling %, stats) into a plan or an ad.
- **Inputs → outputs:** a conflicting instruction → the default to apply, plus what to test if it matters.
- **Rules:**
  - **DO** follow the "Agent default" column unless the user or brand context says otherwise.
  - **DO** treat Sarah's uncited statistics (e.g. "+13.6% likability", "5.43× handwritten fonts", "KFC +56%") as anecdotes. Never put them in ad copy.
  - **DON'T** fabricate proof, scarcity or badge numbers, even where a session seems to tolerate it (row 10).
- **See also:** [rules library](libraries/rules.md), [creative testing system](frameworks/creative-testing-system.md), [TEEP journey](frameworks/teep-journey.md).

## Cross-creator: Tether Lab vs Evolve Copywriting (29)
Added 2026-10-21 with the [Evolve Copywriting](courses/evolve/copywriting/README.md) ingest. Each row's evidence for both sides (lesson and session timestamps) is in the [Evolve contradictions page](courses/evolve/copywriting/contradictions.md#evolve-copywriting-vs-tether-lab-29), same numbering. Conflicts inside the Evolve course itself are listed there too.

| # | Topic | Agent default |
|---|---|---|
| X1 | AI people on screen / AI UGC | AI voiceover and clearly-AI animation OK; no synthetic person delivers a testimonial or first-person result; avoid AI presenters for trust-dependent brands unless a test proves otherwise. |
| X2 | BIG/FAST vs risk reduction | for skeptical/burned-before buyers lead SAFE + EASY with a specific, modest, provable BIG; for novelty-seeking buyers lead NEW + BIG; test both entry points (the L72 three-hook trio already does). |
| X3 | One change per iteration vs bundled changes | one primary change per iteration; when bundling, record every change in the ITER name / "Changes Made" line and don't attribute the result to a single component. |
| X4 | Budget on a breakthrough | use Tether's gradual budget rule; use Evolve's leeway rule (don't switch the creative off after a few bad days) for the ad itself. |
| X5 | Luxury offer stack | true luxury/exclusivity → Tether rules; mass-premium "high perceived value" products → Evolve's over-delivery stack. |
| X6 | Category: create vs fit | position and write ads as different; familiar cues only for functional page elements of everyday products, never for elevated brands. |
| X7 | "Pixar" means three different things | never write "Pixar" alone in a brief. Say "Pixar six-sentence framework (Tether)", "Two Paths / future pacing (Evolve)" or "Pixar-style AI animation (format)". |
| X8 | Fichtean curve definition | name the variant in the brief ("escalating-problem Fichtean (Evolve)" vs "multi-character Fichtean (Tether)"); both are testable. |
| X9 | Logic vs emotion vs information need | deliver the information a high-information buyer needs through a character's emotional belief shift; score drafts on both emotion zone (Tether) and information carried plus story blocks (Evolve). |
| X10 | Naming competitors as the enemy | in ads, frame competitor enemies as a type or approach ("metal wire crates", "powder greens"), as Fable and Grüns do. Name rival brands only in positioning analysis or with client and legal sign-off. |
| X11 | One enemy vs several | one primary brand enemy; single ads may dramatise sub-villains (an ingredient, an enzyme) that serve it. |
| X12 | How much drama a story needs | start from an ordinary, relatable situation, then add a real, specific high-stakes turn; raise drama only as far as the true facts support (no fabrication). |
| X13 | Soft recommendation pitch vs definitive CTA verbs | recommendation voice for the transition and pitch line, then end on one definitive action verb in the final CTA line. |
| X14 | Coined labels vs only the audience's own words | audience call-outs use found labels; test coined labels for the product/mechanism (as Creamunchy names a texture) in separate variants. |
| X15 | How specific an audience call-out should be | signal the audience with a specific situation or visual, attached to a population label large enough to scale. |
| X16 | Camouflage vs recognisable advertising | content-first openings are fine, but never impersonate a news outlet, editorial source or real customer, and follow platform disclosure rules. |
| X17 | One ad through every stage vs one stage per ad | tag an Evolve unaware ad by its entry stage (trigger/exploration) for account structure, but still give it a complete path to the offer. |
| X18 | Video test packaging | launch 3 hook/bridge pairs × 1 hold; once a hook wins, test a second hold/body with one change. |
| X19 | Setup share before the product | Evolve timing for 30–45 s AI-voiceover/B-roll scripts; Tether's setup share for story-led on-camera UGC; run Evolve's "Extended Problem Section" iteration early either way . |
| X20 | Social-proof wording | use the exact documented number when available; tier words only when the documented count sits inside the tier; never round up. |
| X21 | Hook length | on-screen hook text ≤7 words; the spoken hook can run longer if hook + bridge ≤ ~8 s and the first sentence stands alone; slight categorization only inside an objection line, never in the hook. |
| X22 | Imitating competitor ads vs remixing | word-for-word reuse only of our own winning scripts; competitor-sourced ideas carry the structure only, pass the fidelity check, and change the execution (and two psychology axes). |
| X23 | Static text density | max 3 bullets (except all-text native formats); headline ≤7 words where the structure allows. |
| X24 | Reading level vs audience register (cross-course) | simple words and short sentences always; grade 5-7 for mass-market DTC (Evolve); allow elevated vocabulary only for premium/affluent audiences (Tether), still in short sentences. |
| X25 | Bullets under a clear headline | if the headline alone carries the message, test it without bullets; when body copy is needed, use ≤3-4 short bullets instead of a paragraph (see also the "Static text density" item above). |
| X26 | Authority in every ad vs validation first | keep a trust element in every ad, but choose the authority type this audience trusts (peer experience, relatability, the practitioner they now see) and open with validation for expert-burned audiences. |
| X27 | Avatars vs selves as the unit of targeting | use Evolve's avatar → angle as the brief's spine; tag each variant with a Tether self and rotate selves within a proven angle; keep cold ads on Actual/Ideal. |
| X28 | Core message in frame 1 vs withholding in the hook | frame 1 must make the problem or payoff clear enough for the right viewer to self-select; the product/mechanism may be withheld until the bridge; use a promise hook (core message up front) when the context is itself interesting. |
| X29 | How many open loops in a short ad | one main loop from hook to payoff; line-to-line micro-curiosity ("But that's not the real problem…") is fine if each closes within a line or two and never competes with the main question. |

## Terminology slips (Sarah's wording vs the research term)
- "Differentiation effect" / "distinction bias" → **Von Restorff effect** ([page](concepts/heuristics/von-restorff-effect.md)).
- "Halo effect" for borrowing Gordon Ramsay's humor → closer to **association / authority borrowing** ([page](concepts/heuristics/authority-borrowing.md)).
- "Ben Franklin effect" and "observer expectancy effect" are used loosely; see their pages.
- Module 2 materials spell "Effect heuristic"; the slides say **affect heuristic** (correct).
