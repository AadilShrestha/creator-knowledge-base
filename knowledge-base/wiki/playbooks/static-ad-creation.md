# Playbook: Static Ad Creation
> Statics are where a new message gets proven: "dirt cheap to run and dirt cheap to make" [Jun11 0:31:50]. Turn an `angle_brief` into a **static brief**: one core emotion, a weight-ranked layout (headline → image → support), copy inside the line limits, colour/font/face choices, true badges as supporting characters, a definitive CTA, and the next rungs of the **format variation ladder**.

## 🤖 Agent use
- **Use when:** testing a new angle (statics first, then climb to UGC); turning a script's core message into headlines; making variations of a winning static.
- **Inputs → outputs:** `angle_brief` (or a winning static to vary) + product truth sheet + asset bank (shoot photos, video stills, product renders) → `static_brief` per concept (template below) + 3–10 headline variants + a removal-test list.
- **Rules:**
  - DO test the core message on statics first; video only after a static concept wins [Jun18 0:59:15–1:01:19; May21 0:11:31] ([contradictions](../contradictions.md) row 8).
  - DO communicate **one core emotion**: one headline, one CTA; stars, badges and bullets only support it [R1 0:41:46–0:43:52].
  - DO make what matters heaviest; the eye goes heaviest → next heaviest, not in a Z [R1 0:19:55–0:20:57].
  - DO keep headlines **4–7 words, ≤3 lines**; subhead ≤2 lines; call-outs ≤3 lines with the top line bold [R1 0:14:42; 0:36:37–0:38:39].
  - DO make the image show what the headline promises [R1 0:04:13].
  - DO use only true badges: "Only 9 left" was invented in Roast #3; don't [R3 0:15:00] ([contradictions](../contradictions.md) row 10).
  - DON'T use "Shop Now" as the CTA you write; put a definitive CTA in the copy [R1 0:26:52–0:29:09].

## Procedure

### Step 1: Lock the one message
- One sentence: the takeaway + the one emotion (from the angle brief). If you have two emotional lines, cut one [R1 0:41:46]. Blend only two emotions that each won alone, as headline + subhead (Maelove: "The last skincare switch you'll ever make." / "No more guessing. That's our promise.") [Jun4 via [mindstate mapping](../frameworks/mindstate-emotion-mapping.md)].
- Write 5–10 headline candidates. Ask an LLM "What's a simple way to say this?" [R1 0:35:31] and "give me 10 different ways to say <line>" [R3 0:43:07]. Keep the ones in customer language.

### Step 2: Headline and copy limits
| Element | Limit | Notes | Source |
|---|---|---|---|
| Headline | 4–7 words, ≤3 lines | heaviest element, ideally in white space | [R1 0:14:42; 0:36:37] |
| Subhead | ≤2 lines | expands the benefit + self motivation | [R1 0:36:37]; [M4 L7 format](../frameworks/rewriting-ads-for-new-selves.md) |
| Call-outs | ≤3, each ≤3 lines, bold top line | a 1-2-3 "value stack" | [R1 0:37:38–0:38:39] |
| Testimonial | snip to the one core line, real quote only | | [R1 0:15:46–0:16:53] |
| Half-headline (open loop) | half on the creative, payoff in primary text | contrarian "Most people think X… but…" | [R1 0:09:27–0:11:31] |
| Backwards weight | weight the clause that *is* the message | "He put up the tent, but **you brought the flask**" | [R1 0:39:40] |
| Exception | all-text statics can break the word limit because they don't look like ads | | [R1 0:31:14–0:32:15] |

### Step 3: Rank and lay out (visual weight)
1. List every element; assign rank 1 (headline/core claim), 2 (image / key visual proof), 3 (value stack or CTA), or support/OK-to-skip. Nothing outside 1–3 may outweigh rank 3 ([visual weight procedure](../frameworks/visual-weight-hierarchy.md#procedure)).
2. Stack text left-aligned on a 1-2-3 grid; never scatter equal-weight blocks [R1 0:34:26].
3. Let the **image/product break the square** (bite out of a corner, half off-frame) while text stays on the grid [Jun11 0:54:59–0:56:04] ([contradictions](../contradictions.md) row 11c).
4. Rounded pills and buttons [R1 0:48:07–0:51:22].
5. Background: white space, or a repeating pattern of objects the buyer already knows (mandala for wellness, baby bottles for moms) that says the same thing as the text [R1 0:23:01–0:25:34].
6. Metaphor? Give it a literal visual (light switch set to ON) and a consistent verb ("uncover" blind spots) [R1 0:13:39–0:15:00; 0:25:34].

### Step 4: Colour, fonts, faces
| Choice | Rule | Source |
|---|---|---|
| Product colour | Saturation up; test "too saturated" before toning down | [R3 0:48:30–0:50:35] |
| Comparison | Colour on our product; grey/desaturate the "old way" side | [R3 0:35:44–0:37:49] |
| Category palette | Go opposite ("pinks and pastels… I want to be black and green") | [Jun11 0:43:27] |
| Scroll stop | One colour field + "something dead in the center… red, orange, black" | [H4 01:22] |
| Fuchsia test | "Flower pink, not baby pink" runs well on Meta for Sarah (anecdote; test it) | [Jun11 0:54:59] |
| Fonts | Handwritten for hedonic products; structured for utilitarian unless paired with a character | [Jul9 0:06:08–0:09:10] ([font psychology](../concepts/font-psychology.md)) |
| Face | Expression = the headline's emotion (confident: centred brows, lowered lids, smirk); normal bodies; open posture | [R3 0:06:17–0:12:36] |
| Food / ingredient products | Show the ingredients next to the product ("sight smell") | [R1 0:06:19–0:07:22] |
| Premium buyer | More white space, fewer elements, higher-level language; no discounts/bundles for luxury | [R1 0:51:22–0:53:28]; [luxury positioning](../concepts/luxury-positioning.md) |

### Step 5: Badges and proof (supporting characters)
- Max one row each of stars/review count, seal, scarcity/urgency badge, press bar; all small, all true [R3 0:17:51–0:18:56].
- Prefer **typed** proof ("Trusted by 35,000+ Dairy Lovers" pattern) over bare counts ([Fogg](../frameworks/fogg-behavior-model.md)).
- Frame-of-reference badges ("Most customers buy X", "Lasts 180 days") only when true ([offer psychology](../frameworks/offer-and-bundle-psychology.md)).
- Proof type follows the self: Actual = peer reviews; Ideal = transformation/status; Ought = authority/press/safety ([shift table](../frameworks/rewriting-ads-for-new-selves.md#shift-table-what-changes-when-you-move-to-each-self)).
- Any badge claim must be repeated on the landing page [R3 0:15:00–0:17:00].

### Step 6: CTA and primary text
- Definitive CTA in primary text: "See how it works", "Let us show you why…" [R1 0:27:05–0:28:09] ([active CTA language](../concepts/active-cta-language.md)).
- Primary text carries the open-loop payoff and the one supporting proof line; keep "you" language.

### Step 7: Batch and variation plan
- New concept: ~10 statics around one person + one emotion (or 9 = 3 emotions × 3 nuances), 3–5 launched per week ([creative testing](../frameworks/creative-testing-system.md#decision-table-3-cadence-and-batch-size); [contradictions](../contradictions.md) row 7).
- Message not yet proven: vary **format** around one message (static, GIF, carousel) rather than five identical statics [Jun11 0:51:49–0:52:52].
- Winner, team bored: [format variation ladder](../frameworks/format-variation-ladder.md#the-ladder-statics-from-the-source) — close-up → one side → two products → shrunk → in hand → cropped → cherry on top → personified; one variable per variant, same zone and intensity [R3 0:52:41–0:58:59].
- Asset mining: crops and video screen grabs make new statics [Chase 0:53:38–0:55:46].
- Removal tests: same ad minus one element [R1 0:22:01–0:23:01].

## Output: static brief
```markdown
### Static brief: <STA-ANG-nn-v1> · <product> · <concept>
- From angle: ANG-<nn> · Self <A/I/O> · Zone <Z> · Emotion <sub-emotion> · TEEP <stage> · Heuristics <slug, slug>
- One message: "<sentence>"
- Headline (4–7 words, ≤3 lines): "<…>" · alternates: 1) … 2) … 3) …
- Subhead (≤2 lines): "<…>"
- Weight map:
  1. Headline — position <…>, in white space, heaviest
  2. Image — must show <the promise>; face/expression <…>; props <…>
  3. Value stack (3 call-outs, bold top line) OR CTA line
  - Support (small, true): <stars n / seal / badge> (truth_ref <…>) · OK to skip: <…>
- Grid: left-aligned 1-2-3 · Shapes: rounded · Image breaks the square: <how>
- Background: <white | pattern of ___ | colour> · Palette: product saturated; competitor greyed (if comparison); category-opposite: <…>
- Font: <handwritten | structured> because <hedonic | utilitarian>
- Primary text: "<open-loop payoff + 1 proof line + definitive CTA>"
- Asset source: <shoot file | video still | render | AI image (novelty only)>
- Removal tests: A full · B without <…> · C without <…>
- If it wins: ladder rungs next = <1 close-up, 3 two products, 8 personified> · video version = frame 1 "<headline>" before the model/product
- Naming: <STAGE>_<EMOTION>_<angle>_static_v1
```

## Quality gates
- [ ] [Ad scorecard](../rubrics/ad-scorecard.md) ≥ 80, no auto-fail (visual hierarchy criterion used).
- [ ] Squint test: the eye hits ranks 1–3 in order.
- [ ] One emotion, one headline, one CTA; all badges true and repeated on the page.
- [ ] No competitor marks, layout clone or lines (fidelity F1–F7 in [angle remix](angle-remix.md#step-4-fidelity-check-anti-copy-pipeline-design)).
