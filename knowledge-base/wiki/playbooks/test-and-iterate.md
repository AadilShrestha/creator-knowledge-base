# Playbook: Test and Iterate
> Tests are "mini studies. You guys are scientists" [Jun11 0:48:40]. Pick **one learning goal**, launch small batches (3–5 new ads a week), read results **by self, zone and TEEP stage**, change **one variable** on winners, climb the format ladder only after a static wins, and scale slowly. The decision table at the bottom maps **metric pattern → next action**.

## 🤖 Agent use
- **Use when:** scripts/statics are produced and need a launch plan; results are in and you must decide what to make next; a winner seems "fatigued"; a video underperforms its static.
- **Inputs → outputs:** produced assets (named) + angle briefs + budget tier + current account structure + metrics per ad (CTR, CPC, CPA, CVR, ROAS, AOV, add-to-cart, frequency, spend share; LTV/repeat if available) → `test_plan` before launch; `readout` after, with a next-action list that feeds [angle remix](angle-remix.md), [UGC script writing](ugc-script-writing.md) or [static creation](static-ad-creation.md).
- **Rules:**
  - DO decide what you're testing, then pick the structure; "pick a method and stick with it" once the account works [R3 0:23:50–0:26:19].
  - DO test one model per campaign (TEEP stage *or* zone *or* self *or* generation); mixing them means "there's no freaking way you can tell what's going on" [Jun11 0:48:40–0:49:43].
  - DO run 3–5 new ads a week (~20 a month, ≤50) below 8 figures [Jun18 0:51:57–0:54:59]; build up "launch 3 → keep the one with signal → add 3" [Chase 0:57:55–0:59:12].
  - DO iterate winners **one variable at a time** [Jul9 0:29:12–0:32:21].
  - DO test all four zones and keep testing the losing ones after a winner appears [Jun11 0:18:05–0:19:08].
  - DON'T call a frequency of ~2 "fatigue" [R3 0:51:41–0:52:41].
  - DON'T kill an Ought variant in its first ~2 weeks for a slow start; DON'T scale a high-CTR Ideal variant without checking AOV and CVR [M4 L8 02:50; 03:35].
  - DON'T fabricate proof in badge tests; true counts only ([contradictions](../contradictions.md) row 10).

## Procedure

### Step 1: Pick the learning goal (one)
| Goal | When | Structure Sarah gives | Source |
|---|---|---|---|
| Core message | new angle, no data | statics batch; one person + one emotion | [Jun18 0:59:15–1:01:19] |
| Emotion / zone | message direction known, emotion unknown | campaign = emotion, ad sets = zones; or one ad set per emotion, ~9 ads | [Jun11 0:21:13]; [Jun4 0:14:34] |
| Self | a winner exists | one campaign → one ad set → 3 ads (A/I/O), offer/LP/visual constant | [testing by self type](../frameworks/testing-ads-by-self-type.md) |
| TEEP stage | learning how educated the market is | one campaign per stage, ad set per emotion (default); small budget: skip trigger | [TEEP](../frameworks/teep-journey.md#account-structure-two-versions-taught-and-the-recommended-default); [contradictions](../contradictions.md) rows 1–2 |
| Heuristic | message has won | own ad set; one heuristic headline/badge per variant | [R3 0:25:16]; [Jul9 0:29:12] |
| Desire type | headline won but didn't scale | 3 rewrites, one per desire type, + clarifying subtext | [R3 0:43:07–0:46:24] |
| Format | static concept won | formats of one concept in one ad set | [Jun18 0:56:08–0:57:11] |
| Beat the winner | iteration ready | "put it right next to the winner… one campaign, one ad set" | [R3 0:25:44–0:26:19] |

Write the hypothesis: *"<X> beats <control> because <psychology>."* [R3 0:24:54–0:26:19]

### Step 2: Size the batch
| Situation | Batch | Source |
|---|---|---|
| Weekly cadence (<8 figures) | 3–5 new ads/week; ~20/month; ≤50 | [Jun18 0:51:57–0:54:59] |
| Small-batch build-up | launch 3 → keep 1 with signal → add 3, until ~10 live / ~3 "crushing" | [Chase 0:57:55–0:59:12] |
| New concept | ~10 statics (or 9 = 3 emotions × 3 nuances) over 2–3 weeks | [Jun18 1:00:16]; [Jun11 0:31:50] |
| Heuristic batch on a winner | 5–10 variants, same creative | [May7 0:13:46] |
| New message, want reach | ~5 messages × 4 formats ≈ 20 | [Jun11 0:52:52] |
| UGC from our scripts | 3 hooks × 2 bodies = 6 cuts per script (pipeline design) | [UGC script writing](ugc-script-writing.md#step-8-build-the-test-variants-pipeline-design-on-course-rules) |

### Step 3: Testing order (the ladder)
1. **Message** on statics (headline + power image, minimal heuristics) → narrow by CTR [May7 0:14:12–0:14:42].
2. **Heuristics** on the winning message, one per variant [May7 0:13:03–0:15:20].
3. **Desire type** / 10 ways to say the winner [R3 0:43:07].
4. **Combination** copy × image ("customer genomes") [Chase 0:56:48–0:57:55].
5. **Format ladder**: static → GIF/carousel → UGC / founder / fake podcast / pro video, message in frame 1 [Jun18 0:59:15–1:01:19; R3 0:18:56–0:21:32].
6. **Self and zone variants** of the proven concept, one goal per campaign.
7. **Product-treatment variations** when the team is bored ([format variation ladder](../frameworks/format-variation-ladder.md)).
Keep three buckets live: net-new experiments (small share), scaling winners, variations of winners (most effort) [Chase 0:21:46–0:22:31].

### Step 4: Name and tag everything
`<STAGE>_<EMOTION>_<angle>_<format>_<variant>_v<n>`, e.g. `EVAL_SECURITY_amazon-knockoffs_static_v1` ([TEEP template](../frameworks/teep-journey.md#output-templates)). Keep a tracking sheet: **ad · self · emotion · intensity/zone · TEEP · heuristic · CPA · CTR · CVR** (+ AOV, LTV), heat-mapped weekly [Jun11 0:38:09–0:39:12]. Label before launch so no retro analysis is needed [Jun11 0:39:12].

### Step 5: Read results
Read-out timing (agent default from the [testing system](../frameworks/creative-testing-system.md#test-plan-output-template), not from the course): CTR day 2–3, CPA/CVR day 4–7; Ought variants ≥2 weeks.

**By self** (Module 4 L8 signatures; [testing by self type](../frameworks/testing-ads-by-self-type.md)):
| Self | Expected signature | Read |
|---|---|---|
| Ideal | high CTR, lower AOV/CVR | prospecting volume; check AOV and CVR before scaling |
| Actual | lower CTR, higher AOV | profitable conversion |
| Ought | slow start, high LTV | don't kill early; best after qualification/retargeting ([contradictions](../contradictions.md) row 17) |

**By zone:** the winning zone gets more budget; the others keep being tested because zones die "as soon as the seasons change… the customer base changes" [Jun11 0:18:05–0:19:08, 0:22:19–0:23:27].

**By TEEP stage** ([read-out table](../frameworks/teep-journey.md#read-out-decision-table-which-stage-won-and-what-to-do)): evaluation wins → educated market, widen the top; trigger wins → nurture; exploration wins → make more content [Jun4 0:21:52–0:22:56; May21 0:11:31].

Baseline against the **median** CAC/CPA, not the best month [Chase 0:30:40–0:31:44].

### Step 6: Change one variable next
| Winner type | Next single variable | Source |
|---|---|---|
| Static message | heuristic headline or badge | [Jul9 0:29:12] |
| Headline didn't scale | desire type | [R3 0:43:07] |
| Copy and image both good | lock copy, rotate image; then lock image, rotate copy | [Chase 0:56:48] |
| Winning static | format (keep message in frame 1, carry the badge) | [R3 0:19:30–0:21:32] |
| Winning UGC | hook first, then creator, then setting (pipeline design, from [creative testing → UGC](../frameworks/creative-testing-system.md#ugc-application-derived)) | |
| Bored with format | product treatment rung | [R3 0:52:41–0:58:59] |
| Two emotion winners | blend: headline A + subhead B | [Jun4 0:46:18–0:49:22] |
| Purchase-stage line wins | paste it into prospecting creatives | [R3 0:12:36–0:14:42] |
| Want to know what an element does | removal test | [R1 0:22:01–0:23:01] |

### Step 7: Scale
- Raise budget in small steps while CPA and CVR hold; feeding it budget is how you learn whether it's a core message [Jun18 0:38:03–0:39:07].
- While scaling, run two "why did it win" hypothesis threads × ~3 statics each [Jun18 0:39:07–0:41:19].
- See the conflict below for the exact increment.

## Decision table: metric pattern → next action
| Metric pattern | Diagnosis | Next action | Source |
|---|---|---|---|
| Holds CPA/CVR as budget rises | likely core message | keep scaling; build format-ladder versions | [Jun18 0:38:03] |
| High CTR, poor CVR or high bounce | vibe mismatch ad ↔ page, or Ideal signature | run [landing-page scorecard](../rubrics/landing-page-scorecard.md); check AOV; write Actual/Ought variant | [Chase 0:08:26–0:09:38]; [M4 L8 02:50] |
| Low CTR but high AOV/ROAS | Actual signature | keep; scale carefully; don't judge on CTR | [M4 L8] |
| Slow start, repeat buyers rising | Ought signature | wait ≥2 weeks before killing | [M4 L8 03:35] |
| Won the test, didn't scale | sensitivity found, exact desire not | desire-type test (10 phrasings → 3 types) | [R3 0:38:53–0:46:24] |
| Two variants within ~$2 CPA, one scales | pick the scalable one | scale it; fold the runner-up's idea in | [Jul9 0:28:09–0:28:55] |
| Static sells, video gets clicks, no sales | message dropped or delayed | message in frame 1, model second, carry the badge | [R3 0:18:56–0:21:32] |
| Video doesn't convert at all | pace/story | test speed → hook → story → creator, then length 2–3 min → 30 s → 15 s | [May14 0:44:50–0:46:50] |
| Frequency ~2, still takes spend, team bored | creator fatigue, not audience fatigue | vary product treatment, one rung at a time | [R3 0:51:41–0:54:47] |
| Every new ad works briefly then dies; ads are per use case | real fatigue: no core emotion | find the one emotion all use cases share; write to identity | [May7 0:17:51–0:20:05; 0:41:36–0:43:43] |
| One zone cranking, others weak | zone fit for now | shift budget; keep testing other zones | [Jun11 0:18:05–0:23:27] |
| Account in one zone, plateauing | emotional stagnation | brief ≥1 concept per missing zone ([landscape audit](competitor-landscape-audit.md)) | [Jun11 0:08:23] |
| Evaluation ads take off | educated market | more exploration/trigger creative | [Jun4 0:21:52] |
| Trigger ads take off | early, low-educated buyers | more exploration and evaluation content | [Jun4 0:21:52–0:22:56] |
| Variant gets no spend next to the winner | structure question (members disagree) | keep the account's working structure; or new ad set in testing campaign | [R3 0:21:32–0:24:54] |
| Record-low CAC month | outlier | don't re-baseline; reinvest | [Chase 0:30:40–0:31:18] |
| Nothing in the batch gets traction | message/emotion misfire, not tactics | back to [valence-intensity diagnostic](../frameworks/valence-intensity-diagnostic.md) ("it's your vibe") and research | [M3 L1](../courses/tether-lab/03-valence-intensity-model/01-the-real-reason-your-ad-isnt-working.md) [01:25] |

## Where the sources conflict
| Topic | Position A | Position B | Use |
|---|---|---|---|
| Scaling increment | +10–15%/day while CPA and CVR hold (default on the [testing system](../frameworks/creative-testing-system.md#scaling-rule) page) [Jun18 0:38:03] | "+10% every other day" (same answer, cautious; the [contradictions](../contradictions.md) default, row 7b) | Start +10% every other day; move to 10–15%/day only while CPA holds. Aligned across the testing system page and contradictions.md row 7b |
| Batch size | Chase: 3 at a time | Sarah: ~10 statics per new concept | 3–5 per week, spread a 10-static concept over 2–3 weeks (row 7) |
| One-variable tests | May 7 / Jul 9: same creative, new headlines | Jun 11: too slow for new messages | one variable for winners; format diversity for new messages (row 6b) |
| Video vs statics | Chase: no video under $5M | Sarah: video once a static concept wins | static first, then video per concept (row 8) |
| TEEP structure | May 21: campaign per generation, all stages per ad set | Jun 4: campaign per stage | campaign per stage (row 1) |
| Ad-library run time as evidence | 90+ days = winner (CreativeOS) | Jun 11: not proof | weak signal only (row 9) |
| Variant next to winner | Bren: duke it out | Khalid: minimum spend; Darian: new ad set | keep what your account is trained on |

## Output templates
```yaml
test_plan:
  id: TP-<yyyymmdd>-<nn>
  learning_goal: message | emotion | zone | self | teep_stage | heuristic | desire_type | format | beat_the_winner
  hypothesis: "<X> beats <control> because <psychology>"
  structure: {campaign: "<…>", ad_sets: ["<…>"], same_as_account_method: true}
  control: {ad: "<name>", headline: "<…>"}
  held_constant: [offer, landing_page, cta, price, creator, format]
  variants:
    - name: "<STAGE>_<EMOTION>_<angle>_<format>_<variant>_v1"
      variable_changed: "<one thing>"
      tags: {zone: Z?, self: "", teep: "", heuristic: "", emotion: ""}
  batch_this_week: <3-5>
  monthly_total: "<n>/20"
  readout: {ctr_day: 3, cpa_cvr_day: 7, ought_min_days: 14}
  keep_rule: "keep the 1 with signal, kill the rest, add 3 variations of the keeper"
  scale_rule: "+10% every other day; up to +10-15%/day while CPA and CVR hold"
  next_if_win: "<heuristic batch | desire-type | format ladder step | self variants>"
```
