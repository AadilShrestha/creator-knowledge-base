# Libraries hub
> The libraries are the fast-lookup layer of the knowledge base: every hook, angle, ad teardown, rewrite, rule and prompt from Sarah Levinger's Tether Lab, deduplicated, tagged (heuristic, zone, self, niche, format) and linked back to its timestamped source.

## 🤖 Agent use
- **Use when:** you need a real precedent fast ("how did Sarah judge a supplement static with too much text?"), the rules that apply to a piece of creative ("what rules apply to CTAs?"), or the exact prompt for an LLM step ("which prompt do I paste to get curiosity hooks?").
- **Inputs → outputs:** the job you're on (from the table below) → the right library → filtered rows (by niche, format, self, zone, heuristic or failure pattern) → a mechanism to remix, a fix to apply, or a prompt to paste.
- **Rules:**
  - DO start a full workflow from the [playbooks](../playbooks/README.md) (front door: [AGENT-GUIDE.md](../../AGENT-GUIDE.md)); come here for lookups inside a step.
  - DO copy the **mechanism** from a library row (angle, hook structure, emotional move, proof type), never the competitor's line, claim or asset.
  - DO open the row's source link and check the timestamp before quoting Sarah or citing a result.
  - DO treat [rules X1–X11](rules.md#ethics--compliance) as hard constraints: no fabricated proof, true scarcity only, no invented testimonials.
  - DON'T treat `*`, "(wiki)", "derived" or "prompt-output" tags as Sarah's verdicts or as evidence that something works.
- **See also:** [Playbooks](../playbooks/README.md) · [Rubrics](../rubrics/README.md) · [Brands hub](../brands/README.md) · [Heuristics hub](../concepts/heuristics.md) · [Contradictions](../contradictions.md) · [Index](../index.md)

## Shared tagging conventions
- **Heuristics:** slugs of the pages in [`concepts/heuristics/`](../concepts/heuristics.md#every-heuristic-page-catalog) (e.g. `social-proof`, `processing-fluency`).
- **Zones:** Z1 positive/calm · Z2 positive/intense · Z3 negative/calm · Z4 negative/intense ([emotional zones](../concepts/emotional-zones.md)).
- **Selves:** [Actual](../concepts/actual-self.md) · [Ideal](../concepts/ideal-self.md) · [Ought](../concepts/ought-self.md).
- **Provenance:** "(Sarah)" = her verdict; "(wiki)" = a tag from the source page; `*` = inferred by the library; "derived" / "prompt-output" = not evidence that it works.
- **Sources:** every row or rule links to the lesson or session page with a `[mm:ss]` / `h:mm:ss` timestamp, and where relevant to the brand case file in [`brands/`](../brands/README.md).

## Coverage & gaps
- **Built from** the structured units (hooks, angles, teardowns, rewrites, rules tables and bullets) harvested from every lesson, session, concept, framework, brand, resource and tool page of the Tether Lab wiki, plus every prompt on the prompt-bearing pages.
- **Single source:** all libraries cover one course (Tether Lab, Sarah Levinger, with guests Joanna Wallace and Chase Mohseni). When other creators are ingested, add their rows with a `creator` tag rather than mixing them in untagged.
- **Known gaps:** few running-video teardowns; most performance numbers are anecdotal or recalled; some prompts named in sessions were never shared (see [Prompts → Coverage & gaps](prompts.md#coverage--gaps)). Unresolved disagreements live in [contradictions](../contradictions.md).
