# Prompt Library (PDF)
> A 29-page branded PDF by [Sarah Levinger](../people/sarah-levinger.md) (Tether Consumer Insights) containing **prompts #1–#14** of the [Prompt Library](../courses/tether-lab/07-prompt-library/README.md). There are two pages per prompt: Objective + Psychology on the first, Instructions + Format + Output on the second. It's downloadable from the [Ad Lab Toolkit](../courses/tether-lab/06-ad-lab-toolkit/README.md). **Use the per-prompt wiki pages for copy-paste.** They hold the verbatim text, fixes and fill-in blocks.

## 🤖 Agent use
- **Use when:** you need to cite or check the PDF as a source, or hand a human the downloadable file. For running prompts, use the [prompt pages](../courses/tether-lab/07-prompt-library/README.md#master-table).
- **Inputs → outputs:** PDF page number → which prompt and section it holds, and any known error.
- **Rules:** DON'T copy prompt #4 from PDF p.8 without replacing its psychology section (it's #3's). DON'T look for #15 here. It's Skool-only. DO treat the Skool text as canonical (identical wording otherwise).
- **See also:** [Prompt Library hub](../courses/tether-lab/07-prompt-library/README.md) · [Valence + Intensity prompts](valence-intensity-prompts.md) · [Three selves prompts](three-selves-prompts.md)

## What it is
- Toolkit page blurb: "**Ready-to-use psychology prompts to create winning ad ideas fast.** Stop guessing what will convert. This library gives you proven psychology-driven prompts to craft ads that grab attention, trigger emotion, and drive more sales - without starting from scratch."
- Design: dark navy/brown gradient, the ChatGPT logo next to each prompt title, emoji section labels (🎯 Objective, 🧠 Psychology Behind This Prompt, ✍️ Format for Each Concept, ✅ Output Instructions) and an orange "Instructions:" tab. The Tether Consumer Insights logo and a page number sit at the foot of each page.
- Page numbers printed on the pages run 1–28, one lower than the PDF file page (the cover is unnumbered). File pages are cited below as `pNN`.

## Comparison with the Skool pages
- A word-level comparison of every prompt shows **identical wording** between PDF and Skool for #1–#3 and #5–#14. The only differences are the title line, the page numbers, and hyphenation across line breaks (e.g. "high-performers" in #2).
- **#4** differs only in the psychology section (the PDF error above).
- **#15** (The "Why Didn't I See This?" Framework, hindsight bias + bounded rationality) is **not in the PDF**.
- Neither version contains a brand line. Sarah's tutorial says to add your brand, site, landing page or product "at the very, very bottom" ([tutorial notes](../courses/tether-lab/07-prompt-library/README.md#video-tutorial-how-to-use-the-prompt-library)).
