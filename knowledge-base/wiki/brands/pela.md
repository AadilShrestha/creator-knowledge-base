# Pela
> Plant-based phone cases positioned against plastic. **Sarah's agency client** ("an ad we generated for Pela"); the course's model for correct badge scarcity, 3-heuristic stacking and authority *without* an expert.

## 🤖 Agent use
- **Use when:** tearing down eco / "better material" product ads; adding a scarcity badge to a static; stacking fluency + affect + authority; raising emotional intensity of a pretty-but-flat ad.
- **Inputs → outputs:** our product's material/USP + enemy (e.g. plastic) → a contrarian headline, a one-word affect line, expert-sounding proof terms and (only if true) a scarcity badge.
- **Rules:**
  - DO create authority with language an expert would use ("plant-based biopolymer", "20-ft. drop guarantee"): authority bias "doesn't have to be just a quote" ([M2 L5 02:12](../courses/tether-lab/02-heuristics-101/05-stacking-psychology-for-growth.md)).
  - DO let one feeling word ("worry") do the affect work; "doesn't have to be a full-on… story" ([M2 L5 01:49](../courses/tether-lab/02-heuristics-101/05-stacking-psychology-for-growth.md)).
  - DO keep the base fluent: few colours, calm background, one product ([M2 L5 01:00](../courses/tether-lab/02-heuristics-101/05-stacking-psychology-for-growth.md)).
  - DO use badge scarcity ("Our best styles are selling out quick!") only when true; quantity limits beat time limits ([M2 L2 01:00–01:35](../courses/tether-lab/02-heuristics-101/02-using-biases-that-sell.md)).
  - IF the ad is pretty but soft ("Serving spring…") THEN add an enemy and proof to raise intensity ([M3 L4 05:27–05:30](../courses/tether-lab/03-valence-intensity-model/04-diagnosing-emotional-misfires.md), wiki interpretation).
- **See also:** [Heuristic stacking](../concepts/heuristic-stacking.md) · [Scarcity](../concepts/heuristics/scarcity-heuristic.md) · [Authority bias](../concepts/heuristics/authority-bias.md) · [Valence–intensity diagnostic](../frameworks/valence-intensity-diagnostic.md)

## Transferable lessons (remix for our product)
1. **Name the enemy material/habit** in a contrarian headline ("If X could…, we'd use it").
2. **Cost-to-us vs benefit-to-you** framing ("4X more cost for us… 100% less worry for you") pairs sacrifice with one affect word.
3. **Sound like the expert**: technical material names + guarantee instead of a doctor quote.
4. **Seasonal/pretty ≠ emotional**: pair any aesthetic ad with a higher-intensity sibling.
5. **Scarcity badges only with real stock signals.**
