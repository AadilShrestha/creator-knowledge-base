# Power words - ✍️ Evolve Copywriting (NEW) · Evolve

_Source: `✍️ Evolve Copywriting (NEW)/63. Power words_✍️ Evolve Copywriting (NEW)_Evolve.html` (Skool lesson page text)_

Scan your writing and see if any of these words can be implemented to enhance the emotion of your writing and add higher stakes or more intensity

* Let’s learn → **Let’s steal**
* Took → **Robbed**
* Problem → **Crisis**
* Found out → **Uncovered**
* Dangerous → **Deadly**
* Tip → **Secret**
* Said → **Exposed**
* Made → **Engineered**
* Mistake → **Catastrophe**
* Tool → **Weapon**
* Easy → **Hack**

**Even More:**

* Issue → **Threat**
* Bad → **Toxic**
* Wrong → **Fatal**
* Risk → **Gamble**
* Loss → **Destruction**
* Failure → **Collapse**
* Concern → **Warning**
* Soon → **Now**
* Quick → **Instant**
* Fast → **Rapid**
* Start → **Trigger**
* Show → **Prove**
* Help → **Save**
* Learn → **Master**
* Find → **Hunt**
* Clue → **Evidence**
* Notice → **Catch**
* Ignore → **Refuse**
* Against → **Battle**
* Stop → **Kill**
* Avoid → **Escape**
* Prevent → **Defend**
