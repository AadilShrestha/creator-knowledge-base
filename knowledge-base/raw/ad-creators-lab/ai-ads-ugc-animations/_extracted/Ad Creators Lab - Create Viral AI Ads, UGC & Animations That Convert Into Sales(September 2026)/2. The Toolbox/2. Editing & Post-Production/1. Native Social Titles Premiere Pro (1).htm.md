### 1\. Install the Social Media Text Tool Template

* Open Premiere Pro and go to the **Graphics Templates** panel.

* Click the **\+** button and locate the provided Mogrt file **(social media text tool down below).**

* Click **Install** to add it to your template library.



---

### 2\. Apply a Caption Style

* Drag the installed Mogurt onto your timeline where you want on\-screen text.

* In the **Essential Graphics** panel, select a style



---

### 3\. Edit the Caption Text

* Double‑click the placeholder text

* Type your desired copy (e.g., “Replace your current toothbrush”).

* Press **Enter** to wrap long lines as needed.



---

### 4\. Set the Correct Font

* In the **Essential Graphics** panel, change the font to **Roboto Black**.

* If Roboto Black isn’t installed, download it from **Google Fonts** or **Adobe Fonts**, then select it.



---

### 5\. Adjust Colors \& Background

* Use the template’s native color settinhd for text and outlines.

* Select a background option that best suits your style.



---

### 6\. Resize \& Position the Caption Box

* Drag the caption box size handle to resize.

* Position the text away from important visuals (e.g., below the product or speaker’s face).



---

### Alternative for Non‑Premiere Users

* If you don’t use Premiere Pro, search online for a similar caption tool or ask for recommendations.

* Contact the team if you need help locating an equivalent template
