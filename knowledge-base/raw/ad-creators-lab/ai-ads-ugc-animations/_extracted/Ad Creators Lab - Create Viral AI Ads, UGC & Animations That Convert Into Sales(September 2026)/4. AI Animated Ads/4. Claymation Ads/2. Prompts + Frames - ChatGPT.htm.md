* Script (or idea)

* GPT (custom GPT / ChatGPT / Claude)

* Image generator (**Nanobanana 2**)

* Image editor (for fixing \+ consistency)

* Reference images (for same character)

# What you do

### Step 1: Add your script

* Drop your script into GPT

* Click: *turn into claymation storyboard*

* If no script → ask for ideas instead



---

### Step 2: Get scenes \+ prompts

GPT will:* break script into scenes

* create claymation image prompts for each scene



---

### Step 3: Generate images

* copy prompts

* paste into your image tool (e.g. Nanobanana 2\)

* generate one image per scene



---

### Step 4: Repeat fast

* duplicate prompt

* run multiple scenes quickly

* build all images



---

### Step 5: Fix images (optional)

* remove elements if needed (e.g. effects)

* edit images to prepare for animation



---

### Step 6: Keep same character

If character changes:* save the image

* use it as a reference

* switch to image editing (not generation)

* generate new scenes with same person



---

### Step 7: Prepare for animation

* download images

* separate elements if needed (for transitions)
