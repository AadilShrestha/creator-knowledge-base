## SOP: Generate Song\-Style Ad Scripts Using the Prompt Workflow

### Objective

Create song\-style ad scripts tailored to a specific avatar, product, and awareness stage using the prompt workflow. This SOP helps a team member generate usable lyrics, style guidance, and visual ideas for ad creation without needing to write from scratch.### Key Steps

 **1\. Gather the source material for the prompt** [0:20](https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=20 "https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=20")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-3-singing-animation-ads-2-create-song-styl-9333f2/img01.png>)  
* Collect the input document or webpage for the product.

* Use whatever is available:
	+ Research document
	
	+ Website copy
	
	+ Notes with pain points, objections, and solutions* Make sure the source material clearly describes the product and its benefits.

* If the document is simple, that is fine; it does not need to be highly formatted.

 **2\. Run the script\-generation prompt** [0:37](https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=37 "https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=37")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-3-singing-animation-ads-2-create-song-styl-9333f2/img02.png>)  
* Open the prompt tool and paste in the source material.

* Click **Run Prompt**.

* Wait for the prompt to analyze the product and identify the core selling points.

* Confirm that the output reflects the main product themes before moving forward.

 **3\. Choose the song style and length** [0:53](https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=53 "https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=53")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-3-singing-animation-ads-2-create-song-styl-9333f2/img03.png>)  
* Select the desired song genre when prompted.

* If you are unsure, use the option to ask the tool to recommend a genre.

* Choose the ad length, such as:
	+ 30 seconds
	
	+ 45 seconds* If you do not know the best length, ask the tool to recommend one based on the campaign goal.

 **4\. Confirm or enter the target audience** [1:23](https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=83 "https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=83")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-3-singing-animation-ads-2-create-song-styl-9333f2/img04.png>)  
* Review whether the research document already identifies the target market.

* If the target audience is missing or unclear, enter it manually.

* Be specific about the avatar, such as:
	+ Moms age 50\+
	
	+ Dads age 40\+
	
	+ Social\-media\-native users ages 15–34* Use the audience details to help the tool recommend the best genre and tone.

 **5\. Review the genre recommendation and select the best fit** [1:41](https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=101 "https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=101")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-3-singing-animation-ads-2-create-song-styl-9333f2/img05.png>)  
* Review the suggested genres based on the target market.

* Compare the options and choose the one that best matches the audience and offer.

* Example recommendations may include:
	+ Pop
	
	+ R\&B
	
	+ Hyperpop* Select the genre that best supports the ad’s energy and platform fit.

 **6\. Select the awareness stage and ad angle** [2:24](https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=144 "https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=144")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-3-singing-animation-ads-2-create-song-styl-9333f2/img06.png>)  
* Review the recommended angle and awareness stage.

* Choose the option that best matches the customer’s current level of awareness.

* Example:
	+ Angle: "Whiter teeth in 7 days without the zaps"
	
	+ Awareness stage: Solution aware* If needed, ask the tool for other angles or awareness stages to compare before deciding.

 **7\. Use alternative angles if the first recommendation is not ideal** [2:58](https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=178 "https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=178")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-3-singing-animation-ads-2-create-song-styl-9333f2/img07.png>)  
* If the suggested angle does not fit, request more options.

* Ask for additional angles and awareness stages to explore.

* Review the alternatives and choose the one that best aligns with the campaign objective.

* Use this step when you want to test different messaging directions before finalizing the script.

 **8\. Generate and extract the final script** [3:44](https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=224 "https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=224")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-3-singing-animation-ads-2-create-song-styl-9333f2/img08.png>)  
* Once the genre, length, audience, and angle are selected, let the prompt generate the final output.

* Copy the lyrics directly from the result.

* Save the lyrics for use in Suno or the next production step.

* Treat this output as the working script draft for the ad.

 **9\. Review style guidance and visual ideas** [4:08](https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=248 "https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=248")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-3-singing-animation-ads-2-create-song-styl-9333f2/img09.png>)  
* Check the style notes included in the output.

* Use the suggested music style details, such as:
	+ Upbeat pop
	
	+ Bright female lead
	
	+ BPM guidance* Review the visual ideas provided for different creative formats.

* Use the suggestions to plan visuals such as:
	+ Animated character
	
	+ Pixel object
	
	+ Claymation\-style visuals

 **10\. Refine the script to include unique product mechanisms** [4:39](https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=279 "https://loom.com/share/d64b8a79b1df4534ac0673c7f4979a2c?t=279")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-3-singing-animation-ads-2-create-song-styl-9333f2/img10.png>)  
* Review the script for accuracy and relevance.

* Make sure the unique mechanism or differentiator is included.

* If needed, adjust the output so it highlights the product’s special features.

* Example unique mechanisms mentioned in the transcript include:
	+ Peroxide powder
	
	+ Coconut comfort* Use this step to ensure the ad is not just a song, but also a persuasive marketing asset.

### Cautionary Notes

* Do not skip the audience step; the genre and angle depend on who you are targeting.

* Make sure the awareness stage matches the customer’s level of familiarity with the problem and solution.

* Review the generated lyrics for accuracy before using them in production.

* Confirm that the unique mechanism is represented clearly so the ad does not feel generic.

* If the source document is vague, the prompt may require you to re\-enter target market details.

### Tips for Efficiency

* Use the prompt’s recommendation features when you are unsure about genre, length, or angle.

* Keep a reusable research document template with pain points, objections, and product benefits.

* Start with the recommended angle and only explore alternatives if the first option is not strong enough.

* Save approved outputs as examples for future campaigns.

* Use the visual ideas section to speed up creative planning for production teams.
