## How to Turn a Script Into Consistent AI Images for an Ad

 **1\. Start with a script and generate recommended styles** [0:00](https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=0 "https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=0")  
![image.png](<../../../../linked/inline-images/4-ai-animated-ads-1-new-skeleton-ads-3-generating-images-htm-e486d0/img01.png>)* After you insert or choose a script in the skill, the tool first suggests **recommended styles**.

* You can click the style image/link to open a menu and choose a different visual style.

* The tool then creates a **line\-by\-line breakdown** of the script, including:
	+ situations
	
	+ emotions
	
	+ settings
	
	+ props
	
	+ product mentions* The quality of this breakdown improves when you add more context and talk back and forth with the tool about what you want.

 **2\. Generate prompts for each scene** [0:58](https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=58 "https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=58")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-1-new-skeleton-ads-3-generating-images-htm-e486d0/img02.png>)  
* Use a command like **“generate images for 1, 2, 3”** to get exact prompts for the scenes.

* The tool will output:
	+ a prompt for each shot
	
	+ a **character bible** for the main character* The character bible is meant to keep the character visually consistent across all images.

* Even though the example mentions a specific model, the prompt can be used with **any image generator**.

 **3\. Create the first character image to lock in consistency** [1:37](https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=97 "https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=97")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-1-new-skeleton-ads-3-generating-images-htm-e486d0/img03.png>)  
* Copy the character bible and paste it into your image generator.

* Generate the **first image** before making the rest of the scenes.

* This first image acts as the visual reference so the character stays consistent throughout the ad.

* In the demo, the creator uses **MaxFusion** and generates with **Cdream 4\.5** as a low\-cost test model.

 **4\. Review the character and use it as a reference for later shots** [2:11](https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=131 "https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=131")  
* Check whether the generated character matches what you want.

* If needed, make adjustments before moving on.

* For the next scene, copy:
	+ the character bible
	
	+ the scene\-specific prompt section
	
	+ the reference image* This reference\-based workflow is preferred because using only the prompt can lead to small character differences between shots.

 **5\. Generate the remaining scene images with the same character** [2:55](https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=175 "https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=175")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-1-new-skeleton-ads-3-generating-images-htm-e486d0/img04.png>)  
* Use the same character reference for each new shot.

* You can test different image models to see how the style changes.

* The transcript shows examples with:
	+ **Seedream**
	
	+ **GPT\-Image2**
	
	+ **NanoBanana2*** The main goal is to keep the character visually consistent while still matching the scene and style of each shot.

 **6\. Build out the full ad sequence and add missing shots** [3:20](https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=200 "https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=200")  
* Once the first few images look right, continue generating the rest of the scenes.

* The creator notes that they are using this process to build an actual ad.

* After reviewing the generated images, they identify missing coverage, such as:
	+ a community shot
	
	+ a POV screen shot* Add extra prompts for those missing moments so the ad feels complete.

 **7\. Use automation tools if you have them, or prompt manually** [4:23](https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=263 "https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=263")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-1-new-skeleton-ads-3-generating-images-htm-e486d0/img05.png>)  
* If you have **Higgs Field**, **MaxFusion MCP**, or APIs, you can automate the process.

* You can send the instructions directly through tools like **Claude Code** or **Claude**.

* If not, you can still do everything manually by:
	+ writing prompts directly
	
	+ using the layout shown in the demo* Either approach works; the key is keeping the workflow organized and consistent.

 **8\. Move from images into video creation** [4:46](https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=286 "https://loom.com/share/697a1bc45d404941816c33bc35356d81?t=286")  
* After the image set is complete, the next step is to create the video.

* At this point, the image generation workflow is finished and the process transitions into ad video production.
