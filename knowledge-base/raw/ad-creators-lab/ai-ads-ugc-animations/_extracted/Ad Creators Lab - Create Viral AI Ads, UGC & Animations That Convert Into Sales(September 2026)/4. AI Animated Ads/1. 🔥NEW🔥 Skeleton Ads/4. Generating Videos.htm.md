## Generating Video Clips from Image Prompts: Simple Workflow and Advanced Automation

 **1\. Generate video prompts for each image** [0:00](https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=0 "https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=0")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-1-new-skeleton-ads-4-generating-videos-htm-f01db2/img01.png>)  
* Move into the stage where you turn your image prompts into video prompts.

* Ask the tool to **generate video prompts for all images**.

* The output will give you a **motion description for each image**.

* Keep it simple: for this style of content, you usually only need basic motion directions, not complex cinematic instructions.

 **2\. Paste the prompt and attach the image in your video generator** [0:43](https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=43 "https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=43")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-1-new-skeleton-ads-4-generating-videos-htm-f01db2/img02.png>)  
* Open your video generator.

* Paste in the generated video prompt.

* Upload or drag in the corresponding image.

* Choose the video model you want to use.

* The workflow is straightforward: image \+ prompt \+ model \= generated clip.

 **3\. Start with the cheapest model first** [0:50](https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=50 "https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=50")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-1-new-skeleton-ads-4-generating-videos-htm-f01db2/img03.png>)  
* The recommendation is to **begin with the lowest\-cost model**.

* Example: start with **Seedance 1\.5 Pro**.

* If needed, move up to stronger models later.

* Other options mentioned:
	+ **Kling 3\.0 Pro** for best quality
	
	+ **Kling 2\.6** to save credits* The speaker personally likes Seedance 1\.5 Pro for testing results quickly.

 **4\. Match the video duration to the prompt timing** [1:09](https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=69 "https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=69")  
* Pay attention to the duration included in the prompt.

* Example: if the prompt says **4 seconds**, set the video length to **4 seconds**.

* Keep the timing aligned so the motion matches the intended shot.

* Then generate the clip and review the result.

 **5\. Review the generated clip and adjust if needed** [1:38](https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=98 "https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=98")  
* Check how the clip turned out after generation.

* The motion should reflect the prompt, such as a slow push\-in or simple movement.

* Note that **Seedance 1\.5** may add music automatically.

* If you want no music, you can prompt for that or switch to another model like Kling.

 **6\. Use simple motion styles for this format** [2:29](https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=149 "https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=149")  
* The key takeaway is that these videos do **not** need elaborate animation.

* Most examples only use basic motion such as:
	+ a push\-in
	
	+ slight camera movement around the character* Don’t overcomplicate the animation style.

* If you want a different shot, you can change it, but the default format works well with simple motion.

 **7\. Automate the workflow with Cloud Code and an API or MCP** [3:03](https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=183 "https://loom.com/share/d92781b7f2ad47d2b75ad24924c63b2a?t=183")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-1-new-skeleton-ads-4-generating-videos-htm-f01db2/img04.png>)  
* For a more advanced setup, connect **Cloud Code** to an API or MCP.

* Example given: Cloud Code connected to **MaxFusion’s API**.

* This can automate image generation in the correct order.

* If you already use something like **Higgs Field MCP**, you can connect it to Cloud and have it generate the assets inside the workflow.

* This is powerful, but more complex if you’re new to Cloud Code.
