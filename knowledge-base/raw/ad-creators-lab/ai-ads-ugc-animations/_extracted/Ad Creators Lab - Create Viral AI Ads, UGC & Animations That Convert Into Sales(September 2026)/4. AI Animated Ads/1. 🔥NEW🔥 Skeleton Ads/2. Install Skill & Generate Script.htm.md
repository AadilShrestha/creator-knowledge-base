# Install Skill & Generate Script - AI Animated Ads · Ad Creators Lab

_Source: `Ad Creators Lab - Create Viral AI Ads, UGC & Animations That Convert Into Sales(September 2026)/4. AI Animated Ads/1. 🔥NEW🔥 Skeleton Ads/2. Install Skill & Generate Script.htm` (Skool lesson page text)_

Set up and use the Skeleton Ad Director skill in Claude to turn a product website, research document, or objection list into a skeleton\-style ad script and visual concept board. ### Key Steps

 **1\. Install the Skeleton Ad Director skill in Claude** [0:00](https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=0 "https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=0")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-1-new-skeleton-ads-2-install-skill-generat-5d8ca1/img01.png>)  
* Open **Claude**.

* Click the **plus (\+)** icon.

* Select **Create skill**.

* Choose **Upload skill**.

* Upload the Skeleton Ad Director skill file from the provided link.

* Confirm the skill is installed before moving on.

 **2\. Open the skill and start a chat session** [0:12](https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=12 "https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=12")  
* After uploading, optionally review the skill instructions.

* Click the **three dots** menu.

* Select **Try in chat** to begin using the skill immediately.

* In chat, type **/skeleton** to activate the Skeleton Ad Director skill.

* Verify the skill is active when the skeleton ad interface appears.

 **3\. Provide source material for the ad generation** [0:22](https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=22 "https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=22")* Start with one of the following inputs: 
	+ A **script**
	
	+ A **product website**
	
	+ A **research document**
	
	+ A **list of objections*** If using a website, copy the page content and paste it into Claude.

* Use the best available source material to give the skill enough context to generate a relevant ad.

 **4\. Review the generated skeleton\-style script** [0:57](https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=57 "https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=57")* Check that the skill is working by looking for the **"examine skill"** indicator.

* Review the generated output for: 
	+ An **angle**
	
	+ A **skeleton\-style script**
	
	+ A structure that follows the expected pattern, such as **day 1, day 2, day 3*** Read through the draft carefully to determine whether it fits the product and campaign goal.

 **5\. Request a different script style if needed** [1:24](https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=84 "https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=84")* If the first draft is not a good fit, ask for another version.

* Example prompt: **"Give me a different script"** or **"Do a script in a different style."**

* Continue iterating until the script matches the desired tone, structure, and messaging.

* Choose the version that best supports the ad concept.

 **6\. Use the selected script to generate a visual concept board** [1:47](https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=107 "https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=107")* Once you select a script, proceed with the generation process.

* The skill will create a **visual concept board** to help plan the ad.

* Use this board to understand what visuals should appear alongside each line of voiceover.

* Treat this as a first\-draft planning tool for production.

 **7\. Review scene\-by\-scene visual and text suggestions** [2:01](https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=121 "https://loom.com/share/141da7c101584914a01fa5a1099ec453?t=121")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-1-new-skeleton-ads-2-install-skill-generat-5d8ca1/img02.png>)  
* Examine how each line of voiceover is broken into: 
	+ **Situation**
	
	+ **Setting**
	
	+ **Product placement**
	
	+ **On\-screen text suggestions*** Use the visual breakdown to plan shots and creative direction.

* Do not feel required to follow every suggestion verbatim; use it as a strong starting point.

* Refine the concept until you have a usable version 1 for the ad.

### Cautionary Notes

* Do not assume the first generated script is final; always review it for fit and quality.

* If the source material is weak or incomplete, the output may be too generic.

* The visual concept board is a planning aid, not a mandatory production blueprint.

* Make sure the generated script aligns with the product, audience, and campaign objective before using it.
