# Script Visualisation & Image Creation - AI Animated Ads · Ad Creators Lab

_Source: `Ad Creators Lab - Create Viral AI Ads, UGC & Animations That Convert Into Sales(September 2026)/4. AI Animated Ads/2. Crochet Style Ads/3. Script Visualisation & Image Creation.htm` (Skool lesson page text)_

### Objective

Use Claude’s custom skill workflow to turn a script into character\-consistent storyboard frames, then generate matching video prompts and test outputs in Max Fusion. This SOP helps a team member produce consistent visuals and short video clips efficiently while preserving the intended character, scene, and product details.### Key Steps

 **1\. Install the Claude visual skill** [0:00](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=0 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=0")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img01.png>)  
* Open **Claude** and navigate to **Customize → Skills**.

* Click the **plus (\+)** button.

* Select **Create skill** → **Upload skill**.

* Upload the provided skill file as a **.zip**.

* Confirm the skill is installed before moving on.

 **2\. Understand what the skill will generate** [0:12](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=12 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=12")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img02.png>)  
* The skill first checks whether your project uses a **consistent character**.

* If yes, it can generate a **character prompt/description** for reference.

* It then breaks your script into phrases and suggests **multiple visual ideas** for each phrase.

* Use these suggestions to choose visuals that match the script and improve attention/engagement.

 **3\. Launch the skill and upload your script** [1:30](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=90 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=90")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img03.png>)  
* Open the skill by clicking the **three dots** and selecting **Try in chat**.

* Alternatively, use the slash command and run the skill directly.

* Upload or paste your script into the chat.

* Click **Run** and verify the skill is active by confirming it says it is **reading the skill**.

 **4\. Define the character for consistency** [1:53](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=113 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=113")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img04.png>)  
* When prompted, choose the option indicating **yes, there is a character**.

* Provide a clear character description based on your target audience/avatar.

* Include only research\-based details; do **not invent traits** that do not match the avatar.

* Save the generated character reference for later use in image and video generation.

 **5\. Review phrase\-by\-phrase visual suggestions** [2:25](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=145 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=145")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img05.png>)  
* Read through the script breakdown, where each phrase is paired with several visual ideas.

* Compare the options and choose the one that best fits the message, tone, and pacing.

* Use the visual suggestions as a starting point, not a final answer.

* You can revisit and change your selection if a different visual works better.

 **6\. Select a visual and generate the storyboard prompt** [3:02](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=182 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=182")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img06.png>)  
* Choose a phrase and a visual option to test.

* Submit the selected phrase/visual combination back to the skill.

* Review the output, which should include: 
	+ A scene explanation
	
	+ Prompt text for image generation
	
	+ Guidance on whether to use a start frame, end frame, or both* Copy the generated prompt for use in the image tool.

 **7\. Generate the character reference image in Max Fusion** [3:13](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=193 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=193")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img07.png>)  
* Copy the generated character reference.

* Open [**Max Fusion**](https://maxfusion.ai/?via=camilo "https://maxfusion.ai/?via=camilo") **→ Images** and paste the prompt.

* Start with **Seedream** if you want a lower\-cost option.

* Generate the image and wait for the result.

* Use the character image as a reference for all later frames to maintain consistency.

 **8\. Create the start frame for the chosen scene** [3:44](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=224 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=224")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img08.png>)  
* Open the prompt for the selected phrase and visual.

* Copy the **start frame** instructions into the image generator.

* Upload the character reference alongside the prompt.

* Generate multiple versions if needed.

* Choose the frame that best matches the intended action and composition.

 **9\. Refine the frame and preserve scene continuity** [5:05](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=305 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=305")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img09.png>)  
* Compare the generated frame to the intended scene.

* If needed, edit the prompt to improve emotion, pose, or clarity.

* Keep the same background and character reference when generating revisions.

* Make small changes rather than rebuilding the scene from scratch to preserve continuity.

 **10\. Generate the video prompt and set motion endpoints** [6:06](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=366 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=366")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img10.png>)  
* Move to the **Videos** section in Max Fusion.

* Start with **Seedance 1\.5 Pro** if you want the cheapest model.

* Paste the video prompt.

* Set the **start frame** and, if available, the **end frame**.

* Use a short duration such as **5 seconds** for a simple test render.

 **11\. Test higher\-quality video models if needed** [6:39](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=399 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=399")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img11.png>)  
* If the first result is not strong enough, test other models.

* Try **Seedance 2\.0 with references** for better control over multiple images.

* You can also test **Kling** to compare output quality.

* Use the model that best balances quality, motion, and consistency for the scene.

 **12\. Continue storyboarding the next phrases while renders process** [7:19](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=439 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=439")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img12.png>)  
* While images or videos are generating, return to the skill output.

* Move on to the next script phrase and choose the next visual idea.

* Decide whether to show the product early, later, or as a held reveal.

* Repeat the same workflow for each phrase until the full script is covered.

 **13\. Include product details and maintain character reference** [8:48](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=528 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=528")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img13.png>)  
* Make sure the product is included in the prompt when the scene requires it.

* Always reuse the same character reference to avoid unwanted changes.

* If a scene looks off, revise the prompt and regenerate rather than accepting a weak result.

* Keep the visual style, character, and environment aligned across all scenes.

 **14\. Review outputs and iterate until the full script is complete** [10:12](https://loom.com/share/ef62825615864b1c9e3419985015495c?t=612 "https://loom.com/share/ef62825615864b1c9e3419985015495c?t=612")![image.png](<../../../../linked/inline-images/4-ai-animated-ads-2-crochet-style-ads-3-script-visualisation-e28729/img14.png>)  
* Generate visuals and videos for every phrase in the script.

* Compare outputs across models to identify the best\-performing option.

* Use the AI conversationally to request changes, such as: 
	+ “Go back to phrase two, visual one.”
	
	+ “Make him look more sad.”* Continue iterating until the storyboard and video set is complete.

### **Cautionary Notes**

* Do **not** use the generated character description as a prompt unless the workflow specifically instructs you to do so.

* Do **not** invent character traits; base the description on real audience/avatar research.

* Always reattach the **character reference** when generating new frames or scenes, or the character may change.

* Make sure the product is explicitly included in prompts when the scene depends on it.

* Some models may add unwanted elements such as music or inconsistent backgrounds; compare outputs before finalizing.

* Verify the skill is actually running by confirming it is **reading the skill** in Claude.

### **Tips for Efficiency**

* Use **Seedream** first for quick, low\-cost image tests before moving to more expensive options.

* Generate multiple image variations at once so you can choose the strongest frame quickly.

* Keep the same background and character reference when refining scenes to reduce rework.

* Work ahead: while one render is processing, storyboard the next phrase.

* Use short test durations, such as **5 seconds**, to validate motion before committing to longer renders.

* Ask the AI for revisions in plain language instead of restarting the workflow from scratch.
