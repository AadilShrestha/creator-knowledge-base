## Topics

### The Problem: Slow, Expensive Creative Production

* [Traditional creative workflows are slow and costly, relying on briefs, revisions, and external creators.](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=407.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=407.0")

* [**Cost Comparison:**](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3212.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3212.0")
	+ [**Agency/Freelancer:** $150–$500 per creative](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3212.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3212.0")
	
	+ [**AI (Claude Code \+ ArcAds):** \~$0\.30 per image, \~$65 per video](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3212.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3212.0")

	+ [**Claude Code:** The AI agent that executes tasks.](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=1104.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=1104.0")

### Workflow: Generate \& Launch a Campaign

1. [**Define Strategy:** Use the Airtable library to find winning ad formats relevant to your product.](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=1566.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=1566.0")

- **Generate Assets:**
	* [**Video:** Create consistent AI characters using multi\-angle reference shots.](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=1718.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=1718.0")
	
	* [**Image:** Generate 50\+ variations from a single product image using the Airtable templates.](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=1900.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=1900.0")- [**Write Copy:** Claude Code analyzes each creative and pulls top\-performing copy from your ad account, then writes tailored variations.](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=2960.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=2960.0")

- **Launch Ads:**
	* [**Secure API Access:** Connect your Meta ad account via a Facebook app and store the API key in a secure](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=2794.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=2794.0") `.env` [file.](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=2794.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=2794.0")
	
	* [**Automated Upload:** Claude Code uploads all assets and copy, creating ads in Ads Manager.](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3068.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3068.0")
	
	* [**QA \& Approval:** Ads launch paused for human review. An AI agent can also run automated QA checks.](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3068.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3068.0")

### Key Principles for Success

* [**Make AI Output Look Real:** Use specific prompts (e.g., "real skin texture," "visible pores") and avoid generic terms ("cinematic," "professional") to create authentic\-looking assets.](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=2047.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=2047.0")

* [**Train AI with Examples:** Feed the system winning ads to deconstruct their style, script, and visual cues, then save the process as a reusable "Skill."](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=2526.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=2526.0")

* [**Use AI for QA:** Employ a separate AI agent to review work from the creation agent, adding a layer of error\-checking.](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3120.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3120.0")

* [**Human Oversight is Essential:** AI handles execution, but humans must define strategy, provide final approval, and ensure compliance.](https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3335.0 "https://fathom.video/share/pfZKjjd3YgcdxXjt7kydQrtegm-RihLs?tab=summary&timestamp=3335.0")
