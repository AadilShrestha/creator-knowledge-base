* Connect the following inputs inside the same workspace:
	+ [**Deep audience research report**](https://www.skool.com/adcreatorslab/classroom/cdcf9f0c?md=1d1c39d256404cf7ab475b2507f9ecec&utm_campaign=skool_link_classroom&utm_content=856ce40d45864b798c7e6fa1d5bb0a32 "https://www.skool.com/adcreatorslab/classroom/cdcf9f0c?md=1d1c39d256404cf7ab475b2507f9ecec&utm_campaign=skool_link_classroom&utm_content=856ce40d45864b798c7e6fa1d5bb0a32")
	
	+ [**Poppy prompt set**](https://drive.google.com/file/d/1pIYMzPeEM7hi6WgPiNH8Xn0WdoQq23VV/view?usp=sharing "https://drive.google.com/file/d/1pIYMzPeEM7hi6WgPiNH8Xn0WdoQq23VV/view?usp=sharing") for headline and creative generation
	
	+ **AI chat model** (Claude Opus 4\.6 is recommended in the transcript)* Make sure the research document is specific to the brand and contains real customer language, pain points, and desired outcomes.

* Keep everything inside Poppy so the workflow stays centralized and fast.

 **2\. Gather audience insights and choose the creative direction** [0:51](https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=51 "https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=51")![generated-image-at-00:00:51](<../../../linked/inline-images/5-static-ads-new-make-static-ads-with-ai-poppy-method-html-020b3b/img01.jpg>)* Review the audience research report for:
	+ Pain points
	
	+ Desired outcomes / mass desires
	
	+ Real phrases customers use* Identify the strongest angle for the campaign.

* In the transcript, the example campaign for boxed wine focuses on **lifestyle** and identity\-based messaging.

* Choose the awareness or desire category that best matches the campaign goal before generating headlines.

  **3\. Collect image ad references from Facebook Ads Library** [2:03](https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=123 "https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=123")![image.png](<../../../linked/inline-images/5-static-ads-new-make-static-ads-with-ai-poppy-method-html-020b3b/img02.png>)![image.png](<../../../linked/inline-images/5-static-ads-new-make-static-ads-with-ai-poppy-method-html-020b3b/img03.png>)  
* Stay inside Poppy and open the **Facebook Ads** search tool.

* Search for the product category or competitor term, such as: **boxed wine**.

* Apply the **Images** filter to find static image ads.

* Sort or review for **longest\-running ads** to identify proven creative patterns.

* Select strong examples that include:
	+ Clear product visibility
	
	+ Benefit\-led text overlays
	
	+ Strong headline treatment
	
	+ Relevant lifestyle or usage imagery* Import the selected ads into Poppy so they can be used as references.

 **5\. Add product reference images to keep AI outputs accurate** [3:16](https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=196 "https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=196")  
![generated-image-at-00:03:16](<../../../linked/inline-images/5-static-ads-new-make-static-ads-with-ai-poppy-method-html-020b3b/img04.jpg>)* Gather multiple product images from the brand website or product page.

* Import these product images into Poppy as a separate reference group.

* Name the group clearly, such as **image references**.

* Ensure the product references show the actual packaging, label, and format so the AI can match the real product.

* This step helps prevent distorted or unrealistic AI\-generated ads.

 **6\. Generate ad prompts from the selected examples** [3:54](https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=234 "https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=234")![generated-image-at-00:03:54](<../../../linked/inline-images/5-static-ads-new-make-static-ads-with-ai-poppy-method-html-020b3b/img05.jpg>)* Run the Poppy prompt by typing "RUN poppy\_prompt" or "Run Static Headlines Prompt" 

* When prompted, choose the desired mass desire or angle, such as **lifestyle**.

* Let the system analyze the imported ad examples and product references.

* Review the generated headline bank and creative ideas.

* Use the output to create multiple prompt variations for image generation.

 **7\. Create multiple image prompts for each ad example** [5:14](https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=314 "https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=314")* Use the prompt that instructs the AI to:
	+ Focus on the chosen awareness level
	
	+ Study the static ad examples
	
	+ Create multiple image prompts for each example
	
	+ Use the product images as references* Generate several prompt variations per example so you have multiple creative directions.

* Aim for a broad set of angles, layouts, and visual treatments.

 **8\. Generate the image ads in Nano Banana Pro** [6:10](https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=370 "https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=370")![image.png](<../../../linked/inline-images/5-static-ads-new-make-static-ads-with-ai-poppy-method-html-020b3b/img06.png>)  
* Switch from Poppy to **Nano Banana Pro** for image generation.

* Open a new image generation conversation.

* Paste one prompt at a time into the generator.

* Start generating multiple images in parallel by opening additional chats or conversations.

* Continue copying prompts into separate chats to keep the workflow organized and efficient.

 **9\. Review generated images and identify issues** [7:20](https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=440 "https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=440")  
![generated-image-at-00:07:20](<../../../linked/inline-images/5-static-ads-new-make-static-ads-with-ai-poppy-method-html-020b3b/img07.jpg>)* Review the generated images as they finish rendering.

* Open the highest\-quality version of each image to inspect details.

* Check for common issues such as:
	+ Incorrect packaging shape
	
	+ Wrong product orientation
	
	+ Misaligned text or layout
	
	+ Visual elements that do not match the real product* Mark any images that need correction before moving to editing.

 **10\. Edit and refine images using AI chat and reference images** [7:31](https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=451 "https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=451")![image.png](<../../../linked/inline-images/5-static-ads-new-make-static-ads-with-ai-poppy-method-html-020b3b/img08.png>)  
* If an image is close but not accurate, use **AI edit** or open a **chat** for refinement.

* Drag in the original image and a better reference image if needed.

* Give a clear instruction describing the exact correction required.

* Example instruction from the transcript: adjust the serving method or product presentation so it matches the reference image.

* Re\-run the edit until the image matches the product and campaign intent.

 **11\. Scale the process by repeating prompt generation and edits** [8:19](https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=499 "https://loom.com/share/1fffc415e0c64e8781ebc72d4f3048e8?t=499")  
![generated-image-at-00:08:19](<../../../linked/inline-images/5-static-ads-new-make-static-ads-with-ai-poppy-method-html-020b3b/img09.jpg>)* Continue generating, reviewing, and refining images in batches.

* Use the same workflow to produce many variations quickly.

* Keep the process centralized so you do not need to jump between multiple platforms.

* Save the strongest creatives for testing and future iteration.

* Build a library of winning ad styles for faster scaling in future campaigns.

  
### Cautionary Notes

* Do not rely on AI alone without strong research; weak inputs can produce poor creative.

* Make sure product reference images are accurate, or the generated ads may show incorrect packaging or details.

* Review all outputs carefully before using them in campaigns, especially for brand accuracy and visual consistency.

* Long\-running ads are useful references, but they should be adapted to your own brand and audience rather than copied directly.

* Higher\-quality models may cost more credits, so monitor usage when scaling.
