## How to Clone a Winning Video Angle by Swapping the Creator in AI

 **1\. Identify a proven video and decide to clone the angle** [0:00](https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=0 "https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=0")* Start with an original video that is already performing well.

* The goal is to keep the same winning structure/angle, but test it with a different creator/avatar.

* This lets you see whether the concept still works when the person in the video changes.

 **2\. Open your AI video workflow and choose the video generation tool** [0:16](https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=16 "https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=16")![image.png](<../../../../linked/inline-images/3-ai-ugc-1-new-clone-winning-ads-2-clone-broll-ugc-ads-htm-bcf6bf/img01.png>)  
* Go to the AI platform/workflow you want to use.

* Choose **Seedance 2\.0** as the video tool.

* If available, use the provided **references** for Seedance inside the workflow.

 **3\. Upload the source video and check the file limits** [0:30](https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=30 "https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=30")* Upload the original video into the video tool.

* Make sure the clip fits the platform requirements:
	+ **2 to 15 seconds** long
	
	+ Up to **50 MB*** If the clip is too long or too large, trim it down first.

* In the example, the clip is 13 seconds, so it is close to the limit but still usable.

 **4\. Capture a screenshot from the video to use as an image reference** [0:47](https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=47 "https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=47")* Click into the uploaded video.

* Take a quick screenshot of the frame you want to modify.

* This screenshot will be used as the base image for changing the person in the scene.

 **5\. Use the image tool to transform the person in the screenshot** [1:04](https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=64 "https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=64")![image.png](<../../../../linked/inline-images/3-ai-ugc-1-new-clone-winning-ads-2-clone-broll-ugc-ads-htm-bcf6bf/img02.png>)  
* Go to the **images** section inside the workflow.

* Upload the screenshot.

* Use AI to edit the person in the image.

* Example prompt used:
	+ **"Change this to a blonde woman with a green pajama top"*** Generate more than one version if needed so you can pick the best result.

 **6\. Review the generated image and choose the best version** [1:18](https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=78 "https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=78")* Wait for the image generation to finish.

* Review the output to confirm the person has been changed correctly.

* In the example, the result is a different\-looking girl than the original.

* Pick the version that best matches the new creator/avatar you want.

 **7\. Feed the new image back into the video workflow as a reference** [1:24](https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=84 "https://loom.com/share/ce6161d38f67447e8393df977b7c90d6?t=84")* Return to the **video** section.

* Add the newly generated image as an **image reference**.

* The workflow can reference content you just created, which makes the process simple and connected.

* Add a prompt that tells the model what to change.

* Example prompt structure:
	+ Reference the video: **"video 1 is an ad of a man testing a pillow"**
	
	+ Instruct the change: **"replace the man for the woman"**
	
	+ Add the image reference: **"image 1"*** Then generate the video.

* The idea is that the new output follows the original winning angle, but with the new avatar swapped in.
